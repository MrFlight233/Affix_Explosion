# 09 - 效果介绍

> 相关文档：[02-名词解释](./02-名词解释.md) | [03-实体介绍](./03-实体介绍.md) | [04-词条介绍](./04-词条介绍.md) | [05-战斗系统](./05-战斗系统.md) | [文档地图](./README.md)

本文是 **效果库** 与 **主动/被动通道引用** 的权威说明。

---

## 一、定位

- **效果库**：独立配方目录。玩家不能把「效果」当第三种物品购买或持有。
- **实体 / 词条**：通过 **主动通道**、**被动通道** 引用效果并填参；负责「何时、对谁（选目标）」。
- **词条「描述」**：原「效果」文案字段，仅风味说明，不参与结算。

---

## 二、效果配方（EffectDef）

| 字段概念 | 说明 |
|----------|------|
| 名称 / 说明 | 可读名；说明可在全物品池展示 |
| 可主动引用 / 可被动引用 | 可多选；制作页按勾选过滤列表 |
| 类型 | 瞬间 / 持续 |
| 属性与运算 | 如生命、耐力、上限类等 |
| 默认数字 / 持续 / 跳伤间隔 | 挂载时可主要覆写数字 |
| 默认结算落点 | 对目标 / 对动作所有者 / 对启动端；挂载可改 |
| 分类 | Admin / 全物品池筛选 |

### 默认勾选经验（非硬锁）

- **瞬间**（如伤害）：默认仅可主动引用；策划可改。
- **持续 / 底盘**：默认可主动也可被动。
- **流血等持续伤害**：用「持续 + 跳动间隔」配置，必须是正规配方，非特例硬编码。

### 删改规则

- 仍被实体/词条引用时 **不可删除**。
- 大改保存时警告影响件数；确认后所有引用处跟随新配方。

---

## 三、主动通道 / 被动通道

### 主动通道

- 是否可触发、触发耗时、耐力消耗、**选目标（打谁）**、效果引用列表。
- 出手命中后，将引用解析为命中效果再进入战斗结算。

### 被动通道

- **总开关**：关闭则整路被动不生效。
- **选目标**、效果引用列表。
- 开关开启且无挂载 → 无被动效果。

### 挂载（EffectBinding）

- 引用效果库 id；主要覆写数字；显示名默认跟配方。
- 可选覆写结算落点；可选子树条件（凑够某词条才生效）。
- 同通道可重复挂同一配方；持续类按合并规则（刷新/叠层等），非一律双倍。

### 两个「对谁」

| 概念 | 写在哪 |
|------|--------|
| 选攻击/受益目标（打谁） | 实体或词条的 **通道** |
| 单条效果结算落点 | **效果配方**（默认）或挂载覆写 |

---

## 四、与战斗的关系

1. 开战前（或构建快照时）把通道引用 **解析** 成引擎已认识的命中效果 / 被动效果。
2. 战斗演算仍走既有命中管道与被动重算；不在战斗中途查效果库。
3. 已删除「被动加武器伤害」特殊机制；加伤请用主动通道挂伤害类效果。

---

## 五、制作与浏览

- **工作流**：先在效果库建配方，再在实体/词条通道中引用（不做边做边新建捷径）。
- **全物品池**：效果库有独立列表（名、说明、默认可引用方式等）；实体/词条详情显示引用的效果。

---

## 六、上线切割

- 旧内联命中/被动列表迁入效果库后删除，不长期双轨。
- 进行中存档、历史战报、他人 BD 匹配池清空；需新开。

---

## 七、以后可能扩展（本期不做）

- 代币池、光环、给相邻单位授予效果等。
- 本期效果库 **不** 承担这些语义；若以后做，应单独立项，避免把通道引用硬塞成光环。
