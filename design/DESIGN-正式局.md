> 选定方向：**B · 工作台统一**

## 1. 视觉主题与氛围

**"局内工作台"** — 外观像生产力工具，内容是爬塔构筑。路人以为在看表格软件；玩家在组 BD、开战、结算。

- 去游戏化：无 fantasy 边框、无 emoji、无羊皮纸
- 与模拟战一致的中性灰、细边框、左指示条选中态
- **构筑控件（商人列表 / BD / 仓库卡片 / 悬浮窗 / pointer 拖拽 / 战斗卡片与日志）直接复用模拟战 `.sb-*` 组件**；壳层布局仍用 `--fg-*` 与方案 B 分栏
- 仓库顶层**允许单独词条**（模拟战 BD 顶层不允许）
- **记忆点**：顶栏约束数字一眼可读 + **商人面板兼作出售落点**（拖入即半价）+ 战斗壳三栏对阵

### DNA 注入（执行时遵守）

| 来源 | 偷什么 |
|------|--------|
| 本仓库 `design/DESIGN.md`（模拟战） | Zinc 中性色板、`--sb-hover/selected` + 3px 左指示条、按钮主色 `#404040`、圆角 6px、动效 ≤200ms |
| Linear 气质（既有系统已吸收） | 顶栏信息条 + 下划线 Tab、无卡片堆砌、靠分割线分区 |
| Notion 气质 | 左树右内容、弱装饰强结构 |

## 3. 排版规则

```
字体栈：-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif
数字：font-variant-numeric: tabular-nums
战斗日志/等宽：ui-monospace, "SF Mono", "Cascadia Code", "IBM Plex Mono", monospace
```

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| 顶栏品牌 | 13–14px | 600 | 「词条爆炸」 |
| 区块标题 | 11–12px | 600 | 出场 BD / Tab |
| 正文 | 12–13px | 400 | 列表、事件卡 |
| 辅助 | 11–12px | 400 | HUD pill、提示 |
| 日志 | 11px | 400 | 战斗日志 |

- 禁用斜体（含中文）
- 行高：正文 1.5；密集列表 1.35
- 中西文之间加空格（盘古之白）

## 4. 组件样式

### HUD Pill
- 浅底 `--fg-accent-subtle`，圆角 4px，内边距 3×8
- 标签次要色，数值 `--fg-text` + tabular-nums

### 按钮
- 默认：白底 + `--fg-border`；hover `--fg-hover`
- 主操作（开始战斗 / 继续）：`#404040` 底 + 白字
- `:active { transform: scale(0.98) }`（≤50ms 可见）
- focus-visible：`0 0 0 2px var(--fg-focus-ring)`

### 下划线 Tab
- 无底无边；激活：字重 600 + 底边 2px `--fg-indicator`
- 切换内容区可 120ms opacity（0.6→1），`prefers-reduced-motion` 归零

### 列表行（BD 树 / 仓库）
- hover / selected + `inset 3px` 左指示条（同模拟战）
- 子级缩进 16–18px，次要文字色

### 事件卡
- 白底 + 1px border，圆角 8px
- 可点选中：边框加深至 `--fg-indicator` 或浅选中底
- 已触发/不可用：降低对比 + 不可点

### 情境坞 / 底栏

- **探险壳：不设底栏出售坞**（出售落点 = 商人面板）。
- **战斗壳**：倍速与暂停在**顶栏**；结束态主按钮「继续」在摘要区或顶栏主 CTA。

### Toast / 异常条
- Toast：深灰底白字，底居中（购买失败、出售成功、存档结果等）
- 网络异常：警告条，文案含「可重试开始战斗」
- 拖入商人出售成功：可用短 Toast 显示「已出售 · +N 金」（可选）

### Tooltip
- 同模拟战：白底边框浅阴影，12px，max-width ≥240px

### 商人面板（购买源 + 出售落点）

- 标题或面板背景在拖拽悬停时进入 `drag-over`（`--fg-drag-over-*`）
- 提示文案：「拖入物品立即半价出售」
- **无论是否已选本回合事件，均可打开**
- 拖入 BD/仓库物品 → `floor(动态价值/2)` 立即入账，物品消失，无确认框

## 5. 布局原则

### 5.1 探险壳

方案 B：左 BD + 右上情景 + 右下仓库；可调分界线。

```
┌──────────────────────────────────────────────────────────┐
│ [返回主菜单][手动存档][开始战斗]  ·  金/回合/阶段/槽位  ·   │
├─────────────────────┬──┬─────────────────────────────────┤
│ 出场 BD（主画布）   │竖│ 上：事件 | 商人                   │
│ ~48%（可调）        │分├───────── 横分界线 ───────────────┤
│                     │界│ 下：仓库常驻                       │
└─────────────────────┴──┴─────────────────────────────────┘
```

顶栏三段：**左操作按钮** · **中数据 pill（居中）** · **右空/战斗倍速**；样式对齐模拟战 `#sb-header`（内边距、圆角按钮、深色主 CTA）。
- 左栏默认约 **48%**（min 280px / max 70%；右栏 min 320px）
- 右上默认约 **55%** 高（上/下各 min 120px）
- 右 Tab 仅 **事件 / 商人**；仓库右下常驻，不进 Tab
- 分界线比例存 `localStorage`（`fg-explore-split`）；战斗壳不显示分界线与仓库
- 事件发奖区产生可拖实例；商人 = 购+售；仓库 = 完整列表
- **区头单层**：出场 BD / 仓库用 `.fg-zone-head`（12px / 600 / `--fg-text-secondary` + 底边分割），不套 legacy `panel-title`
- **空态虚线落点**：`.fg-drop-empty` 撑满栏内剩余高度；BD 文案「拖入实体」，仓库「拖入实体或词条」

### 5.1b 拖拽流转（必须支持）

| 从 → 到 | 结果 |
|---------|------|
| 事件奖励 → BD | 装备 |
| 事件奖励 → 仓库 | 入库 |
| 商人 → BD | 购买并装备 |
| 商人 → 仓库 | 购买并入库 |
| 仓库 → BD | 装备 |
| BD → 仓库 | 卸下 |
| BD → 商人 | 立即半价出售 |
| 仓库 → 商人 | 立即半价出售 |

### 5.1c 战斗壳

对齐模拟战：上方左右友/敌 BD，下方日志与结束态。

```
┌──────────────────────────────────────────────────────────┐
│ （左空）  ·  金 · 回合 · 阶段 · 战斗时间  ·  暂停·倍速     │
├────────────────────────────┬─────────────────────────────┤
│ 我方 BD `.sb-battle-side`  │ 敌方 BD / 空池               │
├────────────────────────────┴─────────────────────────────┤
│ ░░░░░░░░░░░░░ 横分界线（可拖） ░░░░░░░░░░░░░░░░░░░░░░░░░░ │
├──────────────────────────────────────────────────────────┤
│ 战斗日志 `#fg-battle-log` + 结束态摘要 / [继续]            │
└──────────────────────────────────────────────────────────┘
```

结束态顶栏：左 `[继续]` 主 CTA，中区保留用时，右空。

- 左锁定；无商店/仓库/出售拖拽
- 单位卡片复用 `renderEntityCard(..., 'battle')` + `patchBattleValues`；日志 `mountBattleLog`；倍速 `bindPlaybackControls`
- 上下横分界线可拖调 BD/日志面积，比例存 `localStorage`（`fg-combat-split`）
- 结束态后「继续」推进
- 空 BD 可进入战斗壳并结算

### 5.1d 开局 / 读档 / 卡片

- 新游戏 BD、仓库皆空；读档不自动补 starter
- **第一层开放**：与模拟战一致，非 `starter` 实体可放第一层（木桩：有 HP、无动作）；胜负按双方第一层实体 HP，不要求必须有启动端
- 拖入 BD/仓库，以及继续游戏进入探险壳时：可折叠卡片默认折叠
- 仓库独立词条卡展开态展示效果、被动、槽耗/价值等（对齐悬停窗密度）

### 5.2 开始页

- **主操作**：新游戏 / 继续游戏
- **有存档时**：删除存档（继续游戏之下、历史回顾之前）
- **并列入口**：历史回顾、全物品池
- 局内顶栏并列：手动存档、返回开始（确认）；无「更多」折叠

### 5.3 战斗结束态

- 在战斗壳内；摘要：胜/负/空池、本场金币
- 主操作仅「继续」
- 空池占位：「对战池无对手 · 自动获胜」

### 5.4 结算页

- 独立近全屏页；**仅通关**进入
- **三分区**：上总统计（单行横排：左「返回主菜单」，其后标题、徽章、完成回合/金币/胜负场、归档状态）；左下回合列表；右下选中场详情（结果条、双方 BD、全文日志）
- 点左侧场次切换右侧；默认选中第一场；无场次右侧空态
- 列表|详情竖分界、BD|日志横分界可拖（记住比例）
- BD 卡片默认可折叠/展开；不再使用场次内嵌手风琴

### 5.5 历史回顾

- 开始页独立按钮进入
- **打过 ≥1 场**即可入列（进行中）；通关后为已通关
- 列表：时间、胜/负、状态徽章；不显示序号/金币/已打场数/回合上限
- 点进单局：版式同结算只读（共用 `runReview` 三分区壳）；顶栏单行横排（← 返回列表、归档时间、徽章、胜负等）；返回列表
- 分界线拖动行为同结算页

### 5.6 网络异常

- 留在探险；可重试开始战斗

## 7. Do's / Don'ts

✅ DO:
- 出售只通过拖入商人；购买只通过拖到 BD / 仓库，无点击购买按钮
- 商人随时可开（与事件是否已选无关）；仓库右下常驻
- 可拖分界线调 BD / 情景 / 仓库面积，比例本地记忆
- HUD 数字 tabular-nums；拖拽落点用 drag-over
- 危险操作（删档、新游戏覆盖、返回开始）二次确认
- 错误文案带下一步

❌ DON'T:
- 恢复仓库简视、底栏出售坞、局内物品池 Tab、重复的仓库/商人快捷
- 出售再弹确认（已定：立即半价）
- 紫蓝渐变、霓虹、纯黑 `#000`、emoji、斜体
- 网络异常时装成已进入战斗
- 战斗播放改变胜负结果

- **≥1100px**：左 BD + 右三 Tab

- **&lt;768px**：不作为目标机；保证可滚动、主 CTA 可点

## 9. Motion 哲学

与模拟战一致：**不可见的动效**。

- UI ≤ 200ms；`cubic-bezier(0.23, 1, 0.32, 1)`
- 禁止 `transition: all`、`ease-in`、`scale(0)` 入场
- 拖拽 drag-over 即时高亮（0ms 延迟）
- 必须 `prefers-reduced-motion` 兜底
- hover 包 `@media (hover: hover) and (pointer: fine)`

### 工艺密度清单（落地时 ≥5）

1. 品牌 focus 环（`--fg-focus-ring`）
2. 列表选中左指示条
3. `::selection` 浅灰重音底
4. 商人面板 drag-over 出售（签名交互）
5. Toast 入场 translateY + opacity 150ms
