# 02 - 名词解释

> 相关文档：[01-游戏概述](./01-游戏概述.md) | [03-实体介绍](./03-实体介绍.md) | [04-词条介绍](./04-词条介绍.md) | [05-战斗系统](./05-战斗系统.md)

本文档统一定义游戏中所有核心术语，按类别分组。

---

## 一、游戏阶段

### 层（Floor）
游戏进度的最大单位。当前版本仅有一层，后续可扩展。一层包含三轮。

### 轮（Round）
一层中的子单位。一轮包含三个回合：探险、战斗、收集。每层共 3 轮。

### 阶段（Phase）
一轮中的三个步骤，使用编号 `Z` 标识：
- **Z=1 探险阶段**：从事件池随机抽取 3 个事件，玩家选择 1 个触发。可访问固定商人。
- **Z=2 战斗阶段**：自动战斗，不可操作。战斗结果决定是否进入收集阶段。
- **Z=3 收集阶段**：获取战利品（金币、物品），可调整 BD、访问固定商人。

### 阶段编号
格式：`X-Y-Z`
- `X`：当前层数
- `Y`：当前轮数（1~3）
- `Z`：当前阶段（1=探险, 2=战斗, 3=收集）

## 二、实体层级

### 第一层级（Top Level）
出场面板中直接放置的实体，处于嵌套结构的最外层。
- **只有非启动端的实体才能放入其他实体的实体槽位中**。
- **拥有启动端词条的实体只能放在第一层级**，不能放入任何其他实体的实体槽位中（子孙皆不可）。
- 这是因为启动端需要在战斗时间线中独立行动，嵌套会导致行动冲突。

### 子孙实体（Descendant Entity）
放入某个实体槽位中的子实体，以及子实体的子实体（递归）。
- 当父实体行动时，会触发其所有子孙实体中的**主动型装备**。
- 触发时消耗父实体的耐力值。

### 主动型装备（Active Equipment）
拥有"是否主动=true"属性的子孙实体（通常为武器类）。
- 当父实体（启动端）行动时，主动型装备被触发。
- 触发消耗父实体的耐力值 = 装备的耐力消耗值。
- 主动型装备的**攻击类型**决定本次行动的目标选择方式。

### 被动型装备（Passive Equipment）
拥有"是否主动=false"的子孙实体（通常为防具、饰品、容器类）。
- 不参与触发，不消耗耐力。
- 但其属性（护甲、回复等）持续生效于父实体。
- 仍然计入负重。

## 三、物品系统

### 物品（Item）
游戏中最基本的可收集单位。分为**实体**和**词条**两种类型。
所有物品共有属性：价值、占有槽位、重量。

### 实体（Entity）
物理存在的物品。分为**启动端**和**装备**两大类。详见 [03-实体介绍](./03-实体介绍.md)。

### 词条（Affix）
需要附加到实体上才能生效的能力/属性。详见 [04-词条介绍](./04-词条介绍.md)。

### 固定词条（Fixed Affix）
实体自带的词条，不可拆卸、不可升级、不可修改。定义实体的核心特性。

### 动态词条（Dynamic Affix）
可自由装卸的词条，玩家可在实体间任意移动。

### 物品池（Item Pool）
决定玩家可能遇到哪些物品的池子。分为：
- **通用物品**：所有玩家都有权限获取。
- **词条触发物品**：需要玩家出场或仓库中拥有特定词条后才会加入物品池。

### 实体槽位（Entity Slot）
- 部分实体拥有实体槽位，可以容纳子实体。
- 实体槽位数量由实体自身属性 + 词条（容器1/2/3）共同决定。
- 容器的实体槽位数必须 ≥ 被放入子实体的占有槽位数。

### 占有槽位（Slot Cost）
物品（实体或词条）占用的空间大小。在出场面板或容器中，所有物品的占有槽位之和不能超过可用槽位总数。

### 出场（Deploy）
玩家选择上场的实体与词条组合（BD）。出场面板中所有实体和词条的占有槽位之和受出场槽位上限限制。

## 四、商人系统

### 固定商人（Fixed Merchant）
玩家可随时访问的商人（探险和收集阶段均可）。
- 出售范围：物品池中，价值 ≤ `当前轮次 × 10` 的物品。

### 随机商人（Random Merchant）
通过事件池出现的商人。

| 商人类型 | 规则 |
|----------|------|
| 好物商人 | 随机 6 个物品，价值区间 `[上限, 上限+3]` |
| 实体好物商人 | 同上，只出售实体物品 |
| 词条好物商人 | 同上，只出售词条物品 |
| 折扣商人 | 随机 6 个物品，价格 = 原价 × 50% |
| 抽奖 | 随机 6 个物品，免费选 1 个获得 |

---

## 五、经济系统

### 金币（Gold）
游戏中的货币。初始 **100** 金币。
- 出售价格 = 物品初始价值 × 50%（向下取整）。
- 购买价格 = 物品动态价值。

### 价值（Value）
- **初始价值**：物品的基础价值。
- **动态价值**：受词条/事件影响后的当前价值。
- 商人价值上限：`当前轮次 × 10`。

## 六、战斗 — 耐力系统

### 耐力（Stamina）
启动端用于触发子孙主动型装备的能量资源。
- 每个启动端拥有独立的耐力池。
- 耐力在战斗时间线中持续恢复。

### 耐力上限（Max Stamina）
启动端的耐力最大值。不同实体的耐力上限不同。

### 耐力消耗（Stamina Cost）
当启动端行动时，触发子孙主动型装备所消耗的耐力值。
- 消耗量 = 所有被触发的主动型装备的耐力消耗之和。
- 如果当前耐力不足，该次行动被**搁置**。
- 搁置期间耐力持续恢复，一旦达到所需值，**立即**触发行动。

### 耐力恢复速度（Stamina Regen）
耐力每秒自然恢复的数值。单位：点/秒。
- 例：耐力恢复 10/秒 = 每秒恢复 10 点耐力。

### 耐力不足与搁置
```
行动时机到达 → 检查耐力
  ├── 耐力 ≥ 消耗 → 立即行动，扣除耐力
  └── 耐力 < 消耗 → 搁置行动
         └── 等待耐力自然恢复到 ≥ 消耗 → 立即行动（不额外等待耗时计时器）
```
- 搁置不影响时间线上的下一次行动计时——计时器继续运作。
- 搁置期间如果多次行动都因耐力不足被搁置，它们会按顺序排队等待。

## 七、战斗 — 负重系统

### 重量（Weight）
每个实体都拥有重量属性。单位：公斤。

### 负重上限（Max Load）
启动端能承载的子孙实体总重量的最大值。
- 超出负重上限时，该启动端的**所有耐力消耗 +50%**（乘法叠加）。

### 当前负重（Current Load）
启动端下所有子孙实体的重量之和。

### 超重惩罚
```
超重状态 = 当前负重 > 负重上限
超重时：实际耐力消耗 = 基础耐力消耗 × 1.5
```

---

## 八、战斗 — 攻击系统

### 攻击类型（Attack Type）
决定实体在战斗中选择敌方目标的规则。分为两大类：

#### 近战（Melee）
- **默认攻击敌方最上方（第一位）的启动端**。
- 符合直觉：前排肉搏，先打最近的敌人。

#### 远程（Ranged）
- 每个主动型装备/启动端拥有两个攻击目标属性：

| 属性 | 说明 |
|------|------|
| 顺序攻击 | 兜底搜索方向：从上往下 / 从下往上 |
| 优先目标位 | 优先攻击敌方第几位（1/2/3/null） |

### 目标选择流程
1. 确定攻击类型（由被触发的主动型装备决定）。
2. 优先目标位 != null → 检查该位置是否有存活实体，有则攻击之。
3. 否则按顺序攻击方向搜索最近的存活实体。
4. 若敌方无启动端存活 → 战斗胜利。

### 攻击类型来源
- 如果启动端自身没有装备武器（无主动型子孙实体），则使用**自身的攻击类型**。
- 如果装备了多个主动型装备，**每个主动型装备独立触发**，各自按自己的攻击类型选择目标。
  - 例：冒险者装备近战短剑 + 远程长弓，每次行动时短剑攻击第一位、长弓从下往上攻击。

## 九、战斗 — 通用

### 启动端（Starter）
拥有此词条的实体才能参与自动战斗的行动时间线。
- 启动端**只能放在第一层级**。
- 启动端**不能放入**其他启动端的实体槽位中。

### 伤害（Damage）
实体行动时对敌方造成的基础伤害值。

### 护甲（Armor）
减少受到的物理伤害。实际扣血 = max(攻击方伤害 - 防守方护甲, 1)。

### 回复（Regen）
该实体每次行动时自动恢复的生命值。

### 耗时（Action Time）
实体执行一次行动的时间间隔，单位：毫秒。
- 初始耗时：实体自带的行动间隔。
- 动态耗时：受词条/装备影响后的实际行动间隔。
- 耗时 = 0 表示该实体无法行动。

### 生命值（HP）
实体在战斗中的存活指标。HP ≤ 0 时失去战斗能力。

### 活力值（Vitality）
限制同时可出场的启动端数量的点数系统。
- 玩家活力值上限默认 **5**。
- 出场中所有"占用活力N"词条的 N 之和 ≤ 活力值上限。

---

## 十、事件系统

### 事件池（Event Pool）
探险阶段从中随机抽取 3 个事件，玩家选 1 个触发。当前事件类型：
- 好物商人 / 实体好物商人 / 词条好物商人
- 折扣商人 / 抽奖
- （预留：战斗事件、精英事件、Boss 事件）

---

## 公式汇总

| 名称 | 公式 |
|------|------|
| 出售价格 | `floor(物品初始价值 × 50%)` |
| 固定商人价值上限 | `当前轮次 × 10` |
| 好物商人价值区间 | `[上限, 上限 + 3]` |
| 实际伤害 | `max(攻击方伤害 - 防守方护甲, 1)` |
| 活力占用合计 | `Σ 出场中所有"占用活力N"的 N 值` |
| 当前负重 | `Σ 启动端下所有子孙实体的重量` |
| 超重惩罚 | `若 当前负重 > 负重上限 → 耐力消耗 × 1.5` |
| 耐力恢复 | `每秒恢复 耐力恢复速度 点` |
