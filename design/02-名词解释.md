# 02 - 名词解释

> 相关文档：[01-游戏概述](./01-游戏概述.md) | [03-实体介绍](./03-实体介绍.md) | [04-词条介绍](./04-词条介绍.md) | [05-战斗系统](./05-战斗系统.md)

本文档统一定义游戏中所有核心术语，按类别分组。

---

## 一、游戏阶段

### 回合（Round）
游戏进度的基本单位。回合从 1 开始自然递增，无上限。
- 奇数回合（1、3、5…）= 探险阶段
- 偶数回合（2、4、6…）= 战斗阶段
- 取消"层"概念，只保留回合。

### 阶段（Phase）
每个回合包含一个阶段：
- **phase=1 探险阶段**：从事件池随机抽取 3 个事件，玩家选择 1 个触发。可访问固定商人、配置出场 BD。
- **phase=2 战斗阶段**：自动战斗，不可操作。战斗结束（无论胜负）后进入下一回合的探险阶段。

### 阶段流转
```
探险(phase=1) → 战斗(phase=2) → 下一回合探险(phase=1) → 战斗(phase=2) → ...
```

### 金币
- 初始：**90** 金
- 探险阶段金币：`floor((round + 1) / 2) × 10`
- 战斗获胜金币：`10 + round × 5 + 出场槽位数 × 2`

## 二、实体模型（统一模型）

### 实体（Entity）
游戏中的基本战斗单位。所有实体拥有相同的属性结构（hp、maxStamina、staminaRegen、maxLoad）。
- 不再区分"启动端"、"装备"、"主动装备"、"被动装备"等硬编码类别。
- "武器"、"防具"、"饰品"等仅为描述性词条标签。
- 实体放在第一层还是子孙槽位决定了其战斗行为。

### starter 词条
- 拥有 `starter` 词条的实体 = 第一层战斗单位。
- 自身 `isActive=true` 时会独立在时间线上触发动作。
- 子孙中 `isActive=true` 的实体也会被父实体触发。
- **不能放入其他实体的实体槽位中**。

### 无 starter 的实体
- 放在第一层 → 木桩（有 HP 可被攻击，无动作触发）。
- 放入其他实体槽位 → 占用槽位，有 `isActive` 时由父实体触发（消耗父实体耐力）。

### isActive（可触发动作）
- 布尔属性。有（true）= 可在时间线上触发动作；无（false）= 被动属性生效。
- 每个可触发实体独立计时、独立触发、互不阻塞。

### 属性显示规则
- **HP**：始终显示。
- **耐力上限 / 耐力恢复 / HP恢复 / 负重上限**：仅在拥有 `starter` 词条时显示。

---

## 三、实体层级

### 第一层级（Top Level）
出场面板中直接放置的实体，处于嵌套结构的最外层。
- 第一层总槽位 = 当前回合数（round）。
- 只有拥有 `starter` 词条的实体才能参与战斗行动时间线。

### 子孙实体（Descendant Entity）
放入某个实体槽位中的子实体，以及子实体的子实体（递归）。
- 继承父实体的触发机制。
- 重量计入父实体的当前负重。

### 实体槽位（Entity Slot）
- 部分实体拥有实体槽位，可以容纳子实体。
- 实体槽位数量由实体的 `entitySlots` 属性决定。

### 占有槽位（Slot Cost）
实体在父实体槽位中占用的空间大小。
- 第一层总占用 ≤ 第一层槽位数（= round）。

---

## 四、物品系统

### 物品（Item）
游戏中最基本的可收集单位。分为**实体**和**词条**两种类型。
所有物品共有属性：价值、占有槽位、重量。

### 词条（Affix）
需要附加到实体上才能生效的能力/属性。详见 [04-词条介绍](./04-词条介绍.md)。

### 固定词条（Fixed Affix）
实体自带的词条，不可拆卸、不可升级、不可修改。定义实体的核心特性。

### 动态词条（Dynamic Affix）
可自由装卸的词条，玩家可在实体间任意移动。

### 物品池（Item Pool）
决定玩家可能遇到哪些物品的池子。

### 出场（Deploy）
玩家选择上场的实体与词条组合（BD）。

---

## 五、商人系统

### 固定商人（Fixed Merchant）
玩家在探险阶段可随时访问的商人。
- 出售范围：物品池中，价值 ≤ `round × 10` 的物品。

### 随机商人（Random Merchant）
通过事件池出现的商人。

| 商人类型 | 规则 |
|----------|------|
| 好物商人 | 随机 6 个物品，价值区间 `[上限, 上限+3]` |
| 实体好物商人 | 同上，只出售实体物品 |
| 词条好物商人 | 同上，只出售词条物品 |
| 折扣商人 | 随机 6 个物品，价格 = 原价 × 50% |
| 抽奖 | 随机 6 个物品，免费选 1 个获得 |

---

## 六、经济系统

### 金币（Gold）
游戏中的货币。初始 **90** 金币。
- 出售价格 = `floor(动态价值 / 2)`。
- 购买价格 = 物品动态价值。

### 价值（Value）
- **初始价值**：物品的基础价值。
- **动态价值**：受词条/事件影响后的当前价值。
- 商人价值上限：`round × 10`。

---

## 七、战斗 — 耐力系统

### 耐力（Stamina）
启动端用于触发动作的能量资源。
- 每个启动端拥有独立的耐力池。
- 耐力在战斗时间线中持续恢复。

### 耐力上限（Max Stamina）
实体的耐力最大值。

### 耐力消耗（Stamina Cost）
触发可触发动作所消耗的耐力值。
- 如果当前耐力不足，该次行动被**搁置**。
- 搁置期间耐力持续恢复，一旦达到所需值，**立即**触发。

### 耐力恢复速度（Stamina Regen）
耐力每秒自然恢复的数值。单位：点/秒。
- 含子实体装备的耐力加成。

### 耐力不足与并行等待
```
多个可触发实体的行动时机到达 → 各自检查耐力
  ├── 耐力 ≥ 消耗 → 立即行动
  └── 耐力 < 消耗 → 各自搁置
         └── 谁的耐力先恢复到 ≥ 消耗 → 谁先触发（互不阻塞）
```

---

## 八、战斗 — 负重系统

### 重量（Weight）
每个实体都拥有重量属性。单位：**克**（g）。

### 负重上限（Max Load）
启动端能承载的子孙实体总重量的最大值。
- 超出负重上限时，该实体下**所有可触发动作的 staminaCost × 1.5**。

### 当前负重（Current Load）
启动端下所有子孙实体的重量之和。

### 超重惩罚
```
超重状态 = 当前负重 > 负重上限
超重时：实际耐力消耗 = 基础耐力消耗 × 1.5
```

---

## 九、战斗 — 针对系统

### 针对类型（Target Type）
决定实体在战斗中选择目标的规则：

#### 近战
- 默认针对敌方最上方（第一位）的实体。

#### 远程
- 按针对顺序 + 优先目标位选择目标。

| 属性 | 说明 |
|------|------|
| 针对顺序 | 兜底搜索方向：从上往下 / 从下往上 |
| 优先目标位 | 优先针对敌方第几位（1/2/3/null） |

### 针对目标（Target Faction）
可触发动作的对付对象：
- **友方**：效果作用于己方单位。
- **敌人**：效果作用于敌方单位。
- **所有**：效果同时作用于双方。

例：针对目标="友方"、伤害=-10 → 给己方恢复 10 HP。

### 目标选择流程
1. 按 `targetFaction` 筛选候选目标。
2. 优先目标位 != null → 检查该位置是否有存活实体，有则攻击。
3. 否则按针对顺序方向搜索最近的存活实体。

## 十、战斗 — 通用

### 伤害（Damage）
实体行动时对目标造成的基础伤害值。
- **dmg = weaponDamage**（无最小值限制）。
- 正 = 伤害，负 = 恢复 HP，零 = 无效果。

### 耐力恢复（Stamina Regen）
实体在战斗中每秒恢复的耐力值。
- 总耐力恢复 = 自身 staminaRegen + 自身耐力恢复加成 + 子孙实体耐力恢复加成(staminaRegenerationBonus)之和

### 生命恢复（HP Regen）
实体在战斗中每秒恢复的生命值。默认为 0。
- 总生命恢复 = 自身 hpRegen + 自身生命恢复加成 + 子孙实体生命恢复加成(hpRegenerationBonus)之和

### 耐力上限加成（Stamina Bonus）
被动加成：为最外层启动端增加耐力上限。
- 总耐力上限 = 自身 maxStamina + 自身 staminaBonus + 子孙实体 staminaBonus 之和

### 生命加成（HP Bonus）
被动加成：为最外层启动端增加生命上限。

### 耗时（Action Time）
实体执行一次行动的时间间隔，单位：毫秒。

### 生命值（HP）
实体在战斗中的存活指标。HP ≤ 0 时失去战斗能力（死亡）。

### 第一层槽位（First Layer Slots）
替换旧版活力值系统。第一层槽位数量 = 当前回合数。
- 所有第一层实体占用其 `slotCost` 数量的槽位。
- 总占用 ≤ 第一层槽位数量。

### 死亡与复活
- HP ≤ 0 → 死亡：子孙实体退出战斗，动作停止触发。
- HP 恢复到 > 0 → 复活：重新加入战斗，武器重新开始计时。
- 一方所有第一层实体 HP ≤ 0 → 战败。

## 十一、在线对战池

### 对战池（Battle Pool）
玩家异步匹配对战的数据池。玩家进入战斗阶段时，BD 自动上传到对战池，同时从池中随机抽取其他玩家的 BD 作为对手。

### BD（Build / 构筑）
玩家出场面板的完整配置，包含所有第一层实体及其嵌套的子孙实体和词条。序列化为 `DeploySlot[]` JSON 格式存储和传输。

---

## 十二、事件系统

### 事件池（Event Pool）
探险阶段从中随机抽取 3 个事件，玩家选 1 个触发。

---

## 公式汇总

| 名称 | 公式 |
|------|------|
| 探险阶段金币 | `floor((round + 1) / 2) × 10` |
| 出售价格 | `floor(动态价值 / 2)` |
| 固定商人价值上限 | `round × 10` |
| 第一层槽位数 | `round` |
| 实际伤害 | `dmg = weaponDamage`（无最小值，负值=恢复） |
| 当前负重 | `Σ 实体下所有子孙实体的重量` |
| 超重惩罚 | `若 当前负重 > 负重上限 → 耐力消耗 × 1.5` |
| 耐力恢复 | `每秒恢复 (基础耐力恢复 + 装备耐力加成) 点` |
