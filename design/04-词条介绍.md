## 词条属性定义

| 属性名 | 类型 | 说明 |
|--------|------|------|
| 词条名称 | 字符串 | 词条的唯一名称 |
| 类别 | 枚举 | 属性 / 行动 / 伤害 / 防御 / 耐力 / 负重 / 限制 / 特殊 / 实体分类 |
| 初始数值 | 自然数 | 基础数值 |
| 动态数值 | 自然数 | 受其他效果影响后的当前值 |
| 初始价值 | 自然数 | 购买/出售基准价 |
| 动态价值 | 自然数 | 当前价值 |
| 占有槽位 | 自然数 | 占用槽位，默认 1 |
| 是否可重复 | 布尔 | 同一实体上能否叠加多个 |
| 放置前置词条 | 列表 | 实体现有词条要求 |
| 物品池前置词条 | 列表 | 解锁到物品池的条件 |
| 特殊效果 | 字符串 | 词条的具体效果描述 |

## 词条分类体系

词条按类别组织，每种类别有不同作用：

| 类别 | 典型作用 |
|------|----------|
| 属性 | 数值加成（伤害、速度、回复、HP） |
| 行动 | 行为触发（独立行动、连击、反击、先攻） |
| 伤害 | 伤害附加（元素伤害、中毒、debuff） |
| 防御 | 伤害减免（魔抗、闪避） |
| 耐力 | 耐力系统调节（上限、回复、消耗） |
| 负重 | 负重系统调节（上限、轻量化） |
| 限制 | 约束/条件类效果 |
| 特殊 | 特殊机制（吸血、成长、幸运、荆棘） |
| 实体分类 | 实体分类标记（starter、follower、weapon_type、armor_type、accessory_type）——零价值零槽位，仅用于分类识别 |

### 词条依赖关系

部分词条有**前置词条**要求。例如：
- 行动类：连击/反击/先攻 需要 starter
- 防御类：闪避 需要 敏捷
- 部分武器类实体有**池前置词条**（如需要力量/智力解锁到物品池）

### 分类管理

词条的分类（类别字段）由 `categories` 表驱动，管理员可在管理后台的「管理分类」弹窗中增删改查。每个分类有：
- **id**：代码标识（如 `attribute`、`entity_class`），用于代码判断
- **name**：显示名（如「属性」「实体分类」），用于 UI 展示
- **is_entity_class**：标记该分类是否为实体分类标记（原「类别」分类的角色）

`entity_class` 分类下的词条作为实体类型标记，实体的 `fixedAffixes` 中包含这类词条时，`getEntityCategory()` 自动推导其实体类型。

管理员可在制作物品页面自由创建和调整词条模板。

## 命中效果词条（v5.2 新增）

命中效果词条在 `onHitEffects` 字段中配置。武器造成正伤害后自动触发。

| 词条ID | 名称 | 命中效果 | 说明 |
|--------|------|---------|------|
| life_steal | 生命偷取 | `type: life_steal, params: { percent, amount }` | 命中回复启动端 HP。效果始终只对挂载实体的动作生效；挂 starter 时因传播规则也影响子树 isActive 实体 |
| stamina_drain | 削耐 | `type: stamina_drain, params: { percent, amount }` | 命中削减被命中方耐力。效果始终只对挂载实体的动作生效；挂 starter 时同理传播 |

**使用方式**：在 Admin 后台词条编辑表单的「命中效果」配置区选择效果类型并设置百分比/固定值参数。一个词条可配置一个命中效果。如需多个效果叠加，可创建多个词条分别挂载。
