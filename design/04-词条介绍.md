## 词条属性定义

| 属性名 | 类型 | 说明 |
|--------|------|------|
| 词条名称 | 字符串 | 词条的唯一名称 |
| 类别 | 枚举 | 属性 / 行动 / 伤害 / 防御 / 耐力 / 负重 / 容器 / 限制 / 特殊 |
| 初始数值 | 自然数 | 基础数值 |
| 动态数值 | 自然数 | 受其他效果影响后的当前值 |
| 初始价值 | 自然数 | 购买/出售基准价 |
| 动态价值 | 自然数 | 当前价值 |
| 占有槽位 | 自然数 | 占用槽位，默认 1 |
| 是否可重复 | 布尔 | 同一实体上能否叠加多个 |
| 放置前置词条 | 列表 | 实体现有词条要求 |
| 物品池前置词条 | 列表 | 解锁到物品池的条件 |
| 适用目标 | 枚举 | 可行动实体 / 装备实体 / 通用 |
| 特殊效果 | 字符串 | 词条的具体效果描述 |

## 词条搭配思路

### 耐力流
```
耐力强化 + 快速恢复 + 节能 → 极高频率武器触发
适合搭配高伤害武器（法杖、战锤），消除其耐力瓶颈
```

### 负重流
```
负重强化 × 2 + 轻量化 → 穿重型装备不超重
```
