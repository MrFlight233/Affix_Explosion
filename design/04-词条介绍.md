## 词条属性定义

| 属性名 | 类型 | 说明 |
|--------|------|------|
| 词条名称 | 字符串 | 词条的唯一名称 |
| 类别 | 枚举 | 属性 / 行动 / 伤害 / 防御 / 耐力 / 负重 / 容器 / 限制 / 特殊 |
| 初始数值 | 自然数 | 基础数值 |
| 动态数值 | 自然数 | 受其他效果影响后的当前值 |
| 初始价值 | 自然数 | 购买/出售基准价 |
| 动态价值 | 自然数 | 当前价值 |
| 占有槽位 | 自然数 | 占用槽位，默认 1 |
| 是否可重复 | 布尔 | 同一实体上能否叠加多个 |
| 放置前置词条 | 列表 | 实体现有词条要求 |
| 物品池前置词条 | 列表 | 解锁到物品池的条件 |
| 适用目标 | 枚举 | 启动端 / 装备 / 通用 |
| 特殊效果 | 字符串 | 词条的具体效果描述 |

## 词条分类体系

词条按类别组织，每种类别有不同作用：

| 类别 | 典型作用 |
|------|----------|
| 属性 | 数值加成（伤害、速度、回复、HP） |
| 行动 | 行为触发（独立行动、连击、反击、先攻） |
| 伤害 | 伤害附加（元素伤害、中毒、debuff） |
| 防御 | 伤害减免（魔抗、闪避） |
| 耐力 | 耐力系统调节（上限、回复、消耗） |
| 负重 | 负重系统调节（上限、轻量化） |
| 容器 | 扩展实体槽位（container1~container4 递进关系） |
| 限制 | 约束/条件类效果 |
| 特殊 | 特殊机制（吸血、成长、幸运、荆棘） |
| 类别 | 实体分类标记（starter、follower、weapon_type、armor_type、accessory_type）——零价值零槽位，仅用于分类识别 |

### 词条依赖关系

部分词条有**前置词条**要求。例如：
- 容器系列：container2 需要 container1，container3 需要 container2，container4 需要 container3
- 行动类：连击/反击/先攻 需要 starter
- 防御类：闪避 需要 敏捷
- 部分武器类实体有**池前置词条**（如需要力量/智力解锁到物品池）

### 词条 target 字段

`target` 字段控制词条可附加的目标类型：
- `启动端`：仅可附加给拥有 starter 词条的实体
- `装备`：可附加给武器/防具/饰品等被动实体
- `通用`：无限制

管理员可在制作物品页面自由创建和调整词条模板。
