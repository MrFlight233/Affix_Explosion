# 05 - 战斗系统

## 概述

战斗系统采用**基于时间线的全自动回合制**。核心新增机制：
- **耐力系统**：控制武器触发频率
- **负重系统**：超重惩罚耐力消耗
- **攻击类型与目标优先级**：近战/远程的不同目标选择策略

---

## 一、战斗前准备

### 1.1 第一层级检查
- 战斗开始时，系统扫描出场面板，识别所有**第一层级**的实体。
- 拥有**"可行动"词条**的实体加入行动时间线。
- **验证规则**：如果可行动实体位于非第一层级（被嵌套在其他实体中）→ 配置不合法，拒绝开始战斗。

### 1.2 活力值检查
- 计算所有第一层级实体中"占用活力N"词条的 N 值之和。
- 必须 ≤ 玩家活力值上限（默认 **5**），否则无法开始战斗。

### 1.3 构建战斗数据
对每个可行动实体，汇总自身属性 + 所有子孙实体的属性：

| 汇总属性 | 计算方式 |
|----------|----------|
| 总生命值 | 自身 HP + Σ(被动装备 HP 加成) |
| 总护甲 | 自身护甲 + Σ(被动装备护甲加成) |
| 总回复 | 自身回复 + Σ(被动装备回复加成) |
| 动态耗时 | 自身耗时 + Σ(所有装备耗时修正)，最低 500ms |
| 总耐力上限 | 自身耐力上限 |
| 总耐力恢复 | 自身耐力恢复/秒 |
| 当前负重 | Σ(所有子孙实体重量) |
| 负重上限 | 自身负重上限 |
| 主动型装备列表 | 收集所有子孙中"是否主动=true"的实体 |

### 1.4 超重判定
```
if 当前负重 > 负重上限:
    超重状态 = true
    所有耐力消耗 × 1.5
else:
    超重状态 = false
```

## 二、战斗进行

### 2.1 时间线模型

战斗使用毫秒级时间线推进。每个可行动实体根据自己的**动态耗时**在时间线上占据行动节点。

```
时间线: 0ms ──── 1500ms ──── 2000ms ──── 3000ms ──── ...
                    │            │            │
                  匕首         冒险者       法杖
                (耗时1500)   (耗时2000)   (耗时3000)
```

### 2.2 行动流程

```
时间线推进到某个实体的行动节点
         │
         ▼
  ┌─────────────────────┐
  │ 收集该实体所有       │
  │ 主动型子孙装备       │
  └──────────┬──────────┘
             ▼
  ┌─────────────────────┐
  │ 计算总耐力消耗       │
  │ = Σ(各装备耐力消耗)  │
  │ × 超重惩罚(1.0/1.5) │
  └──────────┬──────────┘
             ▼
  ┌─────────────────────┐
  │ 检查当前耐力         │
  └──────────┬──────────┘
             │
    ┌────────┴────────┐
    │ 足够            │ 不足
    ▼                 ▼
  ┌──────────┐   ┌──────────────────┐
  │ 立即行动  │   │ 搁置，等待耐力恢复 │
  │ 扣除耐力  │   │ 恢复足够后立即触发  │
  └─────┬────┘   └────────┬─────────┘
        │                 │
        └────────┬────────┘
                 ▼
  ┌─────────────────────────────┐
  │ 对每个主动型装备独立执行:    │
  │ 1. 按装备攻击类型选目标      │
  │ 2. 计算伤害                 │
  │ 3. 应用效果（火焰/毒素等）   │
  │ 4. 检查反击/闪避/荆棘       │
  │ 5. 应用吸血/重伤等          │
  └──────────────┬──────────────┘
                 ▼
  ┌─────────────────────────────┐
  │ 回复阶段：                   │
  │ HP += 该实体总回复值         │
  └──────────────┬──────────────┘
                 ▼
  ┌─────────────────────────────┐
  │ 时间线注册下一次行动:         │
  │ 下次行动时间 = 当前时间+动态耗时│
  └─────────────────────────────┘
```

### 2.3 耐力恢复机制

耐力在战斗中**持续每秒恢复**，不是离散恢复。

```
耐力恢复公式:
  当前耐力 = min(当前耐力 + 耐力恢复速度 × 时间增量, 耐力上限)
```

**搁置恢复流程：**
1. 行动时机到达，耐力不足 → 进入搁置状态。
2. 每帧（或每秒）检查：`当前耐力 >= 总耐力消耗？`
3. 一旦满足 → **立即解除搁置，执行行动**。
4. 搁置期间，时间线计时器照常运作（下一次正常行动时间不受搁置影响——仅当前行动被推迟）。

**重要**：搁置只推迟当前这次行动，不影响时间线上后续行动的计时。这意味着如果长期耐力不足，可能有多条搁置排队等待。

## 三、攻击目标选择

每个可行动实体/主动型武器拥有两个独立属性：

| 属性 | 说明 | 可选值 |
|------|------|--------|
| **顺序攻击** | 兜底搜索方向（优先目标位不存在/死亡时使用） | 从上往下 / 从下往上 |
| **优先目标位** | 优先攻击敌方第几位（1-based），null=无优先 | 1 / 2 / 3 / null |

### 3.1 目标选择逻辑

```
1. 优先目标位 != null → 检查该位置是否有存活实体
   ├─ 有 → 攻击该位置
   └─ 无 → 进入步骤 2
2. 按 顺序攻击 方向搜索最近的存活实体
   ├─ 从上往下：从 [0] 开始向下搜索
   └─ 从下往上：从最后一个位置开始向上搜索
3. 敌方全部死亡 → 战斗胜利
```

### 3.2 优先级规则

- **优先目标位**的优先级高于**顺序攻击**。
- 优先目标位指定的位置没有存活实体时，立即降级为顺序攻击兜底。
- 顺序攻击的搜索始终能找到最近的存活实体（或判定胜利）。

### 3.3 类型默认约定

| 类型 | 顺序攻击 | 优先目标位 | 说明 |
|------|----------|------------|------|
| 近战（默认） | 从上往下 | 1 | 固定打前排第一位 |
| 远程（默认） | 从下往上 | null | 从后排往前搜索 |
| 远程-精准打击 | 从下往上 | 2 | 优先打第二位，跳过第一位 |
| 远程-后排狙杀 | 从下往上 | 3 | 优先打第三位，跳过前两位 |

### 3.4 示例

```
敌方阵型（从上到下）：
  [0] 前排肉盾
  [1] 战士
  [2] 后排弓箭手

冒险者（顺序:从上往下, 优先1）→ 优先 [0], [0]存在 → 攻击 [0]
短剑（顺序:从上往下, 优先1）   → 优先 [0], [0]存在 → 攻击 [0]
精灵（顺序:从下往上, 优先null） → 无优先, 从下往上搜索 → 攻击 [2]
长弓（顺序:从下往上, 优先null） → 无优先, 从下往上搜索 → 攻击 [2]
弓箭手（顺序:从下往上, 优先2） → 优先 [1], [1]存在 → 攻击 [1]
法杖（顺序:从下往上, 优先3）   → 优先 [2], [2]存在 → 攻击 [2]
```

### 3.5 优先目标位不存在/死亡时

```
敌方只剩 [0] 和 [1]（[2] 已死亡）：

法杖（顺序:从下往上, 优先3）
  → 优先 [2] → [2] 不存在/死亡
  → 降级：从下往上搜索 → [1] 存活 → 攻击 [1]

敌方只剩 [0]（其余死亡）：

弓箭手（顺序:从下往上, 优先2）
  → 优先 [1] → [1] 不存在/死亡
  → 降级：从下往上搜索 → [0] 存活 → 攻击 [0]
```

### 3.6 多主动型装备的目标分配

一个可行动实体可能装备了多个主动型武器。**每个武器独立选目标**：

```
冒险者装备：
  ├── 短剑（顺序:从上往下, 优先1）  → 攻击敌方 [0]
  └── 法杖（顺序:从下往上, 优先3）  → 攻击敌方 [2]

每次行动同时用两个武器攻击不同目标！
```

## 四、伤害计算

### 4.1 单次攻击伤害

```
物理伤害 = max(攻击方总伤害 - 目标总护甲 + 护甲穿透, 1)

其中：
  攻击方总伤害 = 可行动实体基础伤害 + 触发装备的伤害加成 + 词条伤害加成
  护甲穿透     = 锋利等词条提供的护甲穿透值
```

### 4.2 特殊伤害（无视护甲）

| 类型 | 来源 | 计算 |
|------|------|------|
| 火焰伤害 | 火焰附加词条 | +固定值，无视护甲 |
| 毒素伤害 | 毒素词条 | 每回合固定值，持续 3 回合 |
| 反弹伤害 | 荆棘词条 | 受到攻击时反弹固定值 |

```
总伤害 = 物理伤害 + 火焰伤害 + 毒素伤害（该回合触发）
```

### 4.3 计算示例

**示例：完整的攻击结算**
```
冒险者（伤害 5）装备 短剑（伤害+4、锋利） + 火焰附加词条
攻击敌方前排（护甲 3）

物理伤害 = max(5 + 4 - max(3 - 2, 0), 1)    // 锋利穿透 2 护甲
         = max(9 - 1, 1)
         = 8
火焰伤害 = 3（无视护甲）
总伤害   = 8 + 3 = 11
```

**示例：高护甲目标**
```
对战高护甲敌人（护甲 15）
短剑（物理 9, 穿透 2）

物理伤害 = max(9 - max(15 - 2, 0), 1)
         = max(9 - 13, 1)
         = 1  ← 只能造成最低伤害
火焰伤害 = 3
总伤害   = 1 + 3 = 4     ← 火焰伤害成为主要输出！
```

## 五、特殊机制处理

### 5.1 优先级链

```
攻击发起
  → [1] 闪避判定（15% 完全免疫）
       ├─ 闪避成功 → 本轮攻击结束（不触发反击/荆棘）
       └─ 闪避失败 ↓
  → [2] 伤害计算
  → [3] 反击判定（30% 概率）
       └─ 反击命中 → 消耗一半耐力（向下取整）
  → [4] 荆棘判定（固定反弹伤害）
  → [5] 吸血判定（回复伤害 20%）
```

### 5.2 连击机制

- 行动时 25% 概率触发。
- 连击 = 再次触发所有主动型装备，伤害 × 50%。
- 连击**同样消耗耐力**（按 50% 伤害比例，耐力消耗也 × 50%）。
- 连击可能因耐力不足被搁置。
- 连击**不会再次触发连击**。

### 5.3 反击机制

- 受到攻击时 30% 概率触发。
- 反击使用自身基础伤害（不触发装备），伤害 × 50%。
- 耐力消耗 = 正常的一半。
- 反击的目标是**攻击者**（"谁打我就反击谁"）。

### 5.4 中毒机制

- 中毒持续 3 回合（目标行动 3 次后消失）。
- 每层毒独立计时。
- 每回合开始时结算毒伤。
- 毒伤无视护甲。

### 5.5 回复机制

- 实体每次完成行动后触发回复。
- 回复量 = 总回复值 × 重伤修正（正常 1.0，重伤时 0.5）。
- 回复不会超过 HP 上限。

## 六、战斗结算

### 6.1 胜利条件
- 敌方所有可行动实体 HP ≤ 0。

### 6.2 失败条件
- 玩家方所有可行动实体 HP ≤ 0。

### 6.3 奖励

| 奖励项 | 计算方式 |
|--------|----------|
| 基础金币 | `10 + 当前轮次 × 5` |
| 存活奖励 | 每个存活实体 +2 金币 |
| 物品掉落 | 物品池随机 0~2 个 |
| 稀有概率 | 5% + 幸运词条加成（每层 10%） |

### 6.4 失败处理
- 游戏结束，从最近的自动存档重试。

## 八、敌方设计（预留）

### 8.1 敌方模板

| 属性 | 第 1 轮 | 第 2 轮 | 第 3 轮 |
|------|---------|---------|---------|
| 敌人数量 | 1~2 | 2~3 | 3~4 |
| 敌方伤害 | 2~4 | 5~8 | 8~12 |
| 敌方护甲 | 0~3 | 3~6 | 5~10 |
| 敌方 HP | 10~20 | 20~35 | 30~50 |
| 敌方耐力 | 40~60 | 50~80 | 60~100 |
| 敌方耗时 | 2000~3000 | 1500~2500 | 1000~2000 |

### 8.2 敌方阵型安排
- 前排（[0]）：高护甲、高 HP 的肉盾型敌人。
- 中排（[1]）：均衡型敌人。
- 后排（[2]）：高伤害、低护甲的远程敌人。
- 这样的阵型设计使得攻击类型的差异有战术意义。

## 九、平衡参考

### 9.1 战斗时长目标
| 轮次 | 目标时长 | 说明 |
|------|----------|------|
| 第 1 轮 | 15~30 秒 | 教学，玩家基础 BD 可通过 |
| 第 2 轮 | 25~50 秒 | 需要一定的词条搭配 |
| 第 3 轮 | 40~80 秒 | 需要较完整的 BD 体系 |

### 9.2 耐力平衡参考
- 高频武器（匕首、短剑）：低耐力消耗，高恢复比，适合持续输出。
- 低频武器（战锤、法杖）：高耐力消耗，需要耐力强化/节能词条支撑。
- 超重惩罚：设计为有明显痛感的惩罚（+50%），但不至于完全无法战斗。

### 9.3 攻击类型平衡
- 近战：稳定，但只能打前排肉盾。需要足够伤害突破护甲。
- 远程：可绕过前排打后排，但敌方后排通常是高输出低护甲——先消灭可降低团队承伤。
