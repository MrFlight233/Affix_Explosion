## 游戏简介

《Affix Explosion》（词条爆炸）是一款以**词条搭配组建 BD**为核心的**自动战斗肉鸽爬塔游戏**。

- **组 BD**：玩家收集实体（角色、武器、装备等）与词条（属性加成、特殊效果等），自由搭配组合，打造独一无二的战斗配置。
- **爬塔**：携带 BD 推进回合，经历探险、战斗的循环。
- **肉鸽**：每局游戏的事件、对手（对战池）均为随机，重开性极强。

---

## 核心玩法

游戏分为两大核心操作阶段：

### 1. 组 BD（构筑阶段）

- 使用**实体**和**词条**自由搭配，组成出战阵容。
- 实体是基础载体（如冒险者、武器等），词条附加在实体上提供加成。
- 实体之间有嵌套关系（如武器放入冒险者的实体槽位中）。
- 嵌套关系通过**缩进**表示。
- 玩家需要权衡：槽位限制、第一层槽位、词条搭配的协同效应。

### 2. 探险-战斗（爬塔阶段）

- 回合从 1 开始递增；**奇数回合 = 探险**，**偶数回合 = 战斗**。
- 默认 **最大 10 回合**（5 次探险 + 5 次战斗）；上限仅开发/配置可改。
- 循环：探险（选事件、组 BD）→ 战斗（自动）→ 战斗结束态 → 点「继续」→ …
- 回合 10 战斗结束并点「继续」后进入**结算页**（通关），不再进入回合 11。

## 游戏流程

### 开局

- 玩家初始拥有 **90 金币**（配置可改）。
- **BD 区与仓库均为空**；不自动发放/部署默认启动端（如人类）。物品来自事件与商人后再拖入构筑。
- 起始回合：**回合 1，探险阶段**；进入该探险时再发放探险金币（与开局 90 **叠加**）。
- 探险阶段出现 **3 个随机事件**，玩家选择其一触发，触发后不可再选择其它的。
- **读档保真**：存档中 BD/仓库什么样，继续游戏就是什么样；空 BD 不会自动补实体。
- **空 BD 允许开战**（无友方单位时按战斗引擎结算，通常直接败）。

### 流程详述

```
开局(金币:90)
  → 探险(发探险金,选事件,组BD)
  → 开战/战斗(自动) → 战斗结束态 → [继续]
  → 下一探险 …
  → 回合10战斗结束态 → [继续] → 结算页(通关)
```

### 战斗结果与推进

| 结果 | 战斗奖励 | 推进 |
|------|----------|------|
| 获胜（含空池自动胜） | `floor((round+1)/2)×5` | 结束态 → 继续 → 下一探险或结算 |
| 失败 | **0** | 同样结束态 → 继续推进（不中断本局） |

- **通关条件**：打完回合 10（与中间胜负场次无关）。

### 第一层槽位

```
第一层槽位数 = floor((round + 1) / 2)
```

| 回合 | 槽位 |
|------|------|
| 1–2 | 1 |
| 3–4 | 2 |
| 5–6 | 3 |
| 7–8 | 4 |
| 9–10 | 5 |

若配置提高最大回合数，槽位继续按公式随回合增加。

### 物品来源

- 战斗**不掉落**物品。
- 物品来自**事件**与**商人**（种类以后扩展）。
- 事件池现阶段以满足回合推进为准，详细设计另做。

## 界面布局（工作台 · 任务流 + 拖拽流转）

视觉仍为方向 B（`--fg-*` 壳层）。**商人筛选/列表、BD/仓库卡片、悬浮窗、拖拽与战斗面板交互对齐模拟战**（复用 `.sb-*`）。  
详见 [DESIGN-正式局.md](./DESIGN-正式局.md)、[doc/2026-07-30-正式局UI对齐模拟战.md](../doc/2026-07-30-正式局UI对齐模拟战.md)。

### 探险壳

方案 B：左 BD 主画布 + 右上情景（事件|商人）+ 右下仓库常驻；可拖分界线调面积。  
BD/仓库用模拟战实体卡片；商人用模拟战物品池筛选列表；仓库顶层可放单独词条。

```
┌──────────────────────────────────────────────────────────┐
│ 回合 · 阶段 · 金币 · 槽位   [返回主菜单] [手动存档] [开始战斗] │
├─────────────────────┬──┬─────────────────────────────────┤
│                     │  │ 上：事件 | 商人                   │
│ 出场 BD（主画布）   │竖│ · 事件：3 选 1；奖励可拖          │
│                     │分├───────── 横分界线 ───────────────┤
│                     │界│ 下：仓库常驻（入库 / 拖出）        │
│                     │线│                                 │
└─────────────────────┴──┴─────────────────────────────────┘
```

**已去掉：** 仓库简视、底栏出售坞、局内物品池 Tab、仓库进 Tab、顶栏常驻品牌占位。

**规则：**

- **商人**：无论是否已选本回合事件，均可随时打开（右上 Tab）。
- **仓库**：右下常驻，与情景同屏，可直接互拖。
- **购买**：拖到出场 BD = 购买并装备；拖到仓库 = 购买并入库。金币不足则拒绝并提示。商人界面无「购买」按钮。
- **出售**：将物品拖入**打开的商人面板** → 立即按 `floor(动态价值/2)` 卖掉，**无确认框**，不可撤销。
- **事件发奖**：奖励以可拖物品出现在事件结果区；拖到 BD = 装备，拖到仓库 = 入库。
- **分界线**：竖线调 BD/右栏宽；横线调情景/仓库高；比例存本地，刷新后保持。
- **手动存档**：顶栏与「返回主菜单」并列；关键节点仍自动存。

### 拖拽流转表（探险）

| 从 → 到 | 结果 |
|---------|------|
| 事件奖励 → 出场 BD | 获得并装备（槽位/规则不合法则拒绝） |
| 事件奖励 → 仓库 | 获得并入库 |
| 商人 → 出场 BD | 购买并装备 |
| 商人 → 仓库 | 购买并入库 |
| 仓库 → 出场 BD | 装备 |
| 出场 BD → 仓库 | 卸下 |
| 出场 BD → 商人面板 | **立即半价出售** |
| 仓库 → 商人面板 | **立即半价出售** |
| 出场 / 仓库 内排序 | 调整顺序 |

### 战斗壳

```
┌──────────────────────────────────────────────────────────┐
│ 回合 · 战斗中 · 金币（只读）· 时间   暂停  1x 2x 4x Max  │
├──────────┬────────────────────────┬─────────────────────┤
│ 我方 BD  │ 日志 + 结束态摘要       │ 敌方 BD / 空池说明  │
│ （锁定，sb 卡片树）                │ （Solid 日志）      │
└──────────┴────────────────────────┴─────────────────────┘
```

- 无仓库/商人/出售拖拽。
- 卡片 / 日志 / 倍速控件与模拟战共用组件（`ui/build/*`、`mountBattleLog`、`bindPlaybackControls`）。
- 结束态：结果与本场金币 + 主按钮 **继续**（可在摘要区或顶栏主 CTA）。
- 任意结果 → 继续 → 下一探险或（回合 10）结算页。

## 结算页

- 通关后离开局内壳（版式见 DESIGN-正式局）。
- **只回顾战斗回合**（含空池自动胜、失败）。
- 每条可含：双方 BD、结果、金币、全文日志。
- 返回开始页。

## 历史回顾

- 开始页「历史回顾」独立按钮进入；多局列表 → 单局场次（只读，同结算结构）。

## 网络异常（界面）

- 留在探险壳；提示可重试「开始战斗」；不进入战斗壳。

---

## 悬浮提示（Tooltip）

- 鼠标悬停在物品名称上时，弹出悬浮窗显示该物品的完整属性。
- 实体提示内容包括：名称、分类、伤害、生命加成、生命恢复加成、耐力加成、耐力恢复加成、耗时、耐力消耗、负重、价值、固定词条、槽位。
- 词条提示内容包括：名称、类别、效果、价值、前置要求。
- 鼠标移开后悬浮窗自动消失。

## 存档与历史归档

进行中续玩与历次爬塔回顾是**两套数据**。详见 [02-名词解释](./02-名词解释.md)「存档与历史」。

### 进行中存档（每用户 1 份）

- **新游戏**：覆盖进行中存档；**不清除**历史归档。
- **继续游戏**：仅存在未结束的进行中存档时可用。
- **通关**：写入历史归档后，**删除**进行中存档 → 「继续游戏」不可用。
- **手动存档**：探险阶段可点击存档按钮。
- **自动存档节点**：
  1. 进入探险回合之后（已发放探险金、事件已生成）；
  2. 开战时（匹配成功或空池判定后，含本场开战快照）；
  3. 进入战斗结束态时（写入本场战斗记录）；
  4. 通关进入结算时（归档整局后删除进行中存档）。
- **读档**：
  - 当前事件选项与存档**完全一致**；
  - 开战已存、战斗未结束 → 同 BD + 同 seed **重播本场**；
  - 已在结束态 → 回到结束态。
- **保存内容（设计级）**：金币、回合与阶段、仓库、出场 BD、物品池、seed、当前事件与已访问状态、本局已完成战斗列表、开战中则含开战快照。不含成长/层数字段。

### 历史归档（多局）

- 每用户可保留多局爬塔记录，**暂不设上限**。
- 每局含各战斗场次：双方 BD、结果、奖励、全文战斗日志等。
- 供日后「每一次爬塔回顾」使用；新游戏不覆盖历史。
