## 游戏简介

《Affix Explosion》（词条爆炸）是一款以**词条搭配组建 BD**为核心的**自动战斗肉鸽爬塔游戏**。

- **组 BD**：玩家收集实体（角色、武器、装备等）与词条（属性加成、特殊效果等），自由搭配组合，打造独一无二的战斗配置。
- **爬塔**：携带 BD 进入塔中，经历探险、战斗、收集的循环，层层推进。
- **肉鸽**：每局游戏的事件、掉落均为随机生成，重开性极强。

---

## 核心玩法

游戏分为两大核心操作阶段：

### 1. 组 BD（构筑阶段）
- 使用**实体**和**词条**自由搭配，组成出战阵容。
- 实体是基础载体（如冒险者、武器、随从等），词条附加在实体上提供加成。
- 实体之间有嵌套关系（如武器放入冒险者的实体槽位中）。
- 嵌套关系通过**缩进**表示。
- 玩家需要权衡：槽位限制、活力值上限、词条搭配的协同效应。

### 2. 探险-战斗-收集（爬塔阶段）
- 三个回合组成**一轮**，三轮组成**一层**。
- 每回合流程：**探险（选事件）→ 战斗（自动进行）→ 收集（获取战利品）**。

---

## 游戏流程

### 开局
- 玩家初始拥有 **100 金币**。
- 起始阶段编号：**1-1-1**（第一层、第一轮、探险阶段）。
- 探险阶段出现 **3 个随机事件**，玩家选择其一触发。

### 阶段编号规则
格式：`X-Y-Z`
- X = 当前层数，Y = 当前轮数（1~3），Z = 当前阶段（1=探险, 2=战斗, 3=收集）

### 流程详述

```
开局(金币:100) → 探险(Z=1,选事件) → 战斗(Z=2,自动) → 收集(Z=3,奖励)
                   ↑                                        │
                   └────────── 下一轮 ──────────────────────┘
```

## 开始页面

启动游戏后首先看到开始页面，包含三个选项：

| 选项 | 说明 |
|------|------|
| 新游戏 | 开始全新的一局。如果已有存档中的未结束游戏，则自动覆盖。 |
| 继续游戏 | 读取最近一次存档继续游戏。仅在存在未结束的存档时可选（灰色不可用时表示无存档）。 |
| 全物品池 | 查看当前物品池中的所有物品和词条，仅供查看不可操作。 |

## 界面布局

界面分为以下区域：

```
┌──────────────────────┬──────────────────────┐
│                      │                      │
│   出场区域            │   事件/面板区域       │
│   (左上，约70%高)     │   (右上，约70%高)    │
│                      │                      │
├──────────────────────┤                      │
│ 仓库简视区(可收起)    │                      │
├──────────────────────┼──────────────────────┤
│ 功能按钮区(窄条)      │   出售面板(常驻)      │
│ (左下，约15%高)       │   (右下，约30%高)    │
└──────────────────────┴──────────────────────┘
```

### 左上 — 出场区域
- 宽度 50%，高度约 70%。
- 常驻显示当前出场 BD。
- 第一层级：启动端，每个占一行。
- 子孙层级：装备/词条，通过**缩进**表示嵌套关系。
- 每行格式：`名称  伤害+N  护甲+N  耗时ms  负重  价值`
- 出场区内可**自由拖拽排序**。

### 左中 — 仓库简视区
- 宽度 50%，可**收起/展开**。
- 收起时仅显示一行标题栏，展开时显示仓库物品列表。
- 只显示物品**名称**，无详细数据。
- 可从中拖拽物品到出场区或出售面板。
- 物品按添加顺序排列，可自由拖拽排序。

### 左下 — 功能按钮区
- 宽度 50%，高度约 15%，位于左侧最底部。
- 包含三个按钮：**仓库**、**商人**、**物品池**。
- 点击按钮在右侧事件区域打开/关闭对应面板。
- 不设独立的"出售"按钮——出售通过拖入右下出售面板完成。

### 右上 — 事件/面板区域
- 宽度 50%，高度约 70%。
- 动态区域：
  - 探险阶段：显示 3 个随机事件，点击触发
  - 打开仓库时：显示完整仓库面板
  - 打开商人时：显示商店面板
  - 打开物品池时：显示物品池面板

### 右下 — 出售面板
- 宽度 50%，高度约 30%，**常驻显示**。
- 标题："出售（售价 = 原价 50%，不可撤销）"
- 从出场区、仓库区、仓库简视区拖入物品即出售。
- 出售后物品消失，金币增加。

## 面板说明

### 出场面板
- 位于出场区域，常驻显示。
- 物品每行一个，嵌套通过缩进表示。
- 出场区内可自由拖拽排序。
- 可拖拽物品到仓库简视区（卸下）、仓库面板（卸下）或出售面板（出售）。

### 仓库面板
- 在事件区域显示（点击仓库按钮）。
- 物品每行一个，显示完整数据。
- **双向拖拽**：可与出场面板互相拖拽（装备/卸下）。
- 可拖拽物品到出售面板（出售）。

### 仓库简视区
- 位于出场区下方，可收起。
- 仅显示物品名称，按顺序排列。
- **双向拖拽**：可与出场面板互相拖拽。
- 可拖拽物品到出售面板（出售）。
- 可自由拖拽排序。

### 商店面板
- 在事件区域显示（点击商人按钮）。
- 每行一个物品，显示名称、价格、购买按钮。
- **拖拽购买**：
  - 拖拽物品到出场区 → 直接购买并装备到对应槽位
  - 拖拽物品到仓库简视区 → 直接购买并放入仓库
- 也可点击"购买"按钮完成购买。

### 出售面板
- 右下常驻显示，不需要按钮打开。
- 从出场区、仓库面板、仓库简视区拖入物品 → 立即出售，无法撤销。
- 出售价格 = 物品价值的 50%（向下取整）。

### 物品池面板
- 在事件区域显示（点击物品池按钮）。
- 展示当前物品池中所有物品。
- 支持按类别过滤（实体/词条/全部）。
- 仅供查看，不可拖拽。

### 战斗阶段界面

进入战斗阶段（Z=2）时，界面切换为战斗模式：

#### 出场区域（左上）
- **锁定**，不可进行任何拖拽操作。
- 保留当前 BD 展示，供玩家查看。

#### 事件区域（右上）→ 敌人面板
- 切换为**敌人面板**，展示当前敌人的 BD。
- 敌人 BD 结构与玩家 BD 相同：启动端在第一层级，装备/词条通过缩进展示。
- 每行显示敌人的名称、HP、伤害、护甲等数据。

#### 功能按钮区（左下）
- 显示**倍速控制**按钮：0.5x / 1x / 2x
- 默认 1x 速度。
- 玩家可随时切换播放速度。

#### 出售面板区域（右下）→ 战斗日志
- 切换为**战斗日志**面板。
- 实时滚动显示战斗过程中的每一步操作。
- 日志格式：`[时间ms] 攻击者 用 武器 攻击 目标 → 造成 N 伤害（目标HP变化）`
- 战斗结束后显示胜负结果和奖励。

#### 战斗流程
- 战斗开始后自动按时间线运行。
- 根据倍速设置，时间流逝速度相应调整。
- 当一方全部启动端 HP ≤ 0 时战斗结束。
- 胜利：显示奖励，退出战斗界面，进入收集阶段。
- 失败：提示失败，可从存档重试。

## 悬浮提示（Tooltip）

- 鼠标悬停在物品名称上时，弹出悬浮窗显示该物品的完整属性。
- 实体提示内容包括：名称、类别、伤害、护甲、回复、耗时、耐力、负重、价值、固定词条、槽位。
- 词条提示内容包括：名称、类别、效果、价值、前置要求。
- 鼠标移开后悬浮窗自动消失。

## 操作方式

| 操作 | 方式 |
|------|------|
| 拖拽装备 | 从仓库/仓库简视拖到出场区 → 装备 |
| 拖拽卸下 | 从出场区拖到仓库/仓库简视 → 卸下 |
| 拖拽购买 | 从商店拖到出场区 → 购买+装备 |
| 拖拽购买 | 从商店拖到仓库简视 → 购买+入库 |
| 拖拽出售 | 从出场/仓库/仓库简视拖到右下出售面板 → 出售 |
| 排序 | 在出场区/仓库区内拖拽调整顺序 |
| 点击购买 | 在商店面板点击"购买"按钮 |
| 选择事件 | 点击事件卡片 |
| 悬浮查看 | 鼠标悬停在物品上查看详细信息 |

## 存档机制

- 游戏**最多只有 1 个存档**，不存在多槽位概念。
- **自动存档**：进入探险阶段时自动保存。
- **手动存档**：在探险阶段和收集阶段，点击存档按钮保存当前进度。
- **开始页面逻辑**：
  - 新游戏：如果已有存档则直接覆盖，开始新游戏。
  - 继续游戏：读取唯一的存档继续。仅在存档存在且游戏未结束时可用。
  - 全物品池：不需要存档，直接查看。
- 战斗阶段不可存档（战斗中无法保存）。
- 存档保存内容：金币数、仓库物品、出场 BD 配置、当前阶段编号、物品池、成长层数。
