## 核心规则

> **可行动实体只能放在第一层级，不能放入其他实体的实体槽位中。**

实体分为两大类：
- **可行动实体**：拥有完整战斗属性，独立参与战斗时间线。只能放在出场面板第一层。
- **装备实体**：放入可行动实体的实体槽位中，作为子孙实体被触发。分为主动型和被动型。

## 一、可行动实体属性定义

| 属性名 | 类型 | 说明 |
|--------|------|------|
| 实体名称 | 字符串 | 唯一名称 |
| 类别 | 枚举 | 角色 / 随从 |
| 占有槽位 | 自然数 | 在出场面板中占用的槽位 |
| 实体槽位 | 自然数 | 可容纳装备实体的数量 |
| 生命值 | 自然数 | 战斗中的存活指标 |
| 耐力上限 | 自然数 | 耐力最大值 |
| 耐力恢复 | 自然数 | 每秒恢复的耐力值 |
| 负重上限 | 自然数 | 可承载子孙实体的最大总重量 |
| 攻击类型 | 枚举 | 近战 / 远程 |
| 顺序攻击 | 字符串 | "从上往下"或"从下往上"，兜底搜索方向 |
| 优先目标位 | 数字/null | 优先攻击敌方第几位（1=第一位），null=无优先 |
| 基础伤害 | 自然数 | 自身基础伤害（可与装备伤害叠加） |
| 基础护甲 | 自然数 | 自身基础护甲（可与装备护甲叠加） |
| 初始耗时 | 自然数 | 基础行动间隔（毫秒），0 = 无法行动 |
| 初始价值 | 自然数 | 购买/出售基准价格 |
| 固定词条 | 列表 | 不可拆卸的固有词条 |
| 动态词条槽位 | 自然数 | 可附加的动态词条数量上限 |
| 物品池前置词条 | 列表 | 解锁条件 |

## 二、装备实体属性定义

| 属性名 | 类型 | 说明 |
|--------|------|------|
| 实体名称 | 字符串 | 唯一名称 |
| 类别 | 枚举 | 武器 / 防具 / 饰品 / 容器 |
| 占有槽位 | 自然数 | 在父实体中占用的槽位 |
| 实体槽位 | 自然数 | 自身可嵌套子实体的数量 |
| 重量 | 自然数 | 重量（计入父实体负重） |
| 是否主动 | 布尔 | true=主动型（被触发时消耗耐力），false=被动型 |
| 耐力消耗 | 自然数 | 主动型触发时消耗父实体多少耐力 |
| 攻击类型 | 枚举 | 仅主动型有效：近战 / 远程 |
| 顺序攻击 | 字符串 | 仅主动型有效："从上往下" / "从下往上" |
| 优先目标位 | 数字/null | 仅主动型有效：1/2/3/null |
| 伤害加成 | 自然数 | 触发时提供的额外伤害 |
| 护甲加成 | 自然数 | 提供的护甲值 |
| 回复加成 | 自然数 | 提供的每回合回复值 |
| 耗时修正 | 整数 | 对父实体行动耗时的修正（负数=变快） |
| 生命值加成 | 自然数 | 为父实体增加的生命值 |
| 初始价值 | 自然数 | 购买/出售基准价格 |
| 固定词条 | 列表 | 不可拆卸的固有词条 |
| 动态词条槽位 | 自然数 | 可附加的动态词条数量上限 |
| 物品池前置词条 | 列表 | 解锁条件 |

### 顺序攻击枚举值

| 值 | 说明 |
|----|------|
| 从上往下 | 从 [0] 开始向下搜索最近存活实体 |
| 从下往上 | 从最后一个位置开始向上搜索最近存活实体 |

### 优先目标位枚举值

| 值 | 说明 |
|----|------|
| 1 | 优先攻击敌方第一位可行动实体 |
| 2 | 优先攻击敌方第二位可行动实体（跳过第一位） |
| 3 | 优先攻击敌方第三位可行动实体（跳过前两位） |
| null | 无优先目标，直接使用顺序攻击搜索 |

> **目标选择逻辑**：优先目标位 > 顺序攻击。优先目标位指向的实体不存在/死亡时，降级为按顺序攻击方向搜索最近存活实体。敌方全灭即战斗胜利。

## 七、搭配示例

### 示例 1：基础近战 BD
```
出场（第一层级）：
  └── 冒险者（可行动）  负重: 0/30
        ├── 短剑（主动、近战、耐力消耗 15、重量 5）
        └── 皮甲（被动、重量 4）

总负重: 9/30 ✓
每次行动耐力消耗: 15
耐力恢复 10/s → 1.5s 恢复 15 → 可持续输出
伤害: 5 + 4 = 9 | 护甲: 0 + 3 = 3 | HP: 60 + 10 = 70
耗时: 2000 - 200 = 1800ms
```

### 示例 2：超重警告 BD
```
冒险者（可行动）  负重上限: 30
  ├── 战锤（主动、近战、耐力消耗 35、重量 15）
  ├── 盾牌（被动、重量 10）
  └── 锁子甲（被动、重量 8）

总负重: 33/30 ⚠️ 超重！
耐力消耗: 35 × 1.5 = 52（超重惩罚 +50%）
耐力恢复: 10/s → 需要 5.2s 恢复 → 严重拖累输出频率！
建议：将锁子甲换成皮甲（重量 4）→ 总负重 29/30 ✓
```

### 示例 3：远程精准打击 BD
```
冒险者（可行动）  负重: 0/30
  ├── 长弓（主动、远程-从下往上、耐力消耗 22、重量 8）
  └── 力量护符（被动、重量 1）

总负重: 9/30 ✓
每次行动耐力消耗: 22
伤害: 5 + 8 + 3 = 16
长弓从下往上攻击 → 优先击杀敌方后排！
```

### 示例 4：多随从 BD
```
出场（第一层级）：
  ├── 冒险者（可行动）  负重: 9/30
  │     ├── 短剑（主动、近战、耐力消耗 15、重量 5）
  │     └── 皮甲（被动、重量 4）

三线输出：冒险者+短剑打前排、战狼打前排、弓箭手打第二位
```
