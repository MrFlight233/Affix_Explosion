## 核心规则

> **实体即实体。没有硬编码的分类（启动端/装备/武器/防具/饰品/容器只是描述性词条）。**

所有实体拥有相同的属性结构。实体的战斗表现取决于：
- 放在**第一层** + 拥有 `starter` 词条 → 独立参与战斗时间线。
- 放在**第一层** + 无 `starter` 词条 → 木桩（有 HP，可被攻击，不触发动作）。
- 放在**其他实体的槽位中** → 子孙实体，属性叠加给父实体。`isActive=true` 时由父实体触发。

**starter 实体不能放入其他实体的槽位中。**

## 一、统一实体属性定义

所有实体共享以下属性：

| 属性名 | 类型 | 说明 |
|--------|------|------|
| 实体名称 | 字符串 | 唯一名称 |
| 占有槽位(slotCost) | 自然数 | 在第一层或父实体中占用的槽位 |
| 实体槽位(entitySlots) | 自然数 | 自身可嵌套子实体的数量 |
| 重量(weight) | 自然数 | 重量，单位：克(g) |
| 价值(value) | 自然数 | 购买/出售基准价格 |
| HP | 自然数 | 基础生命值 |
| 耐力上限(maxStamina) | 自然数 | 耐力最大值 |
| 耐力回复(staminaRegen) | 自然数 | 每秒恢复的耐力值 |
| 负重上限(maxLoad) | 自然数 | 可承载子孙实体的最大总重量 |
| 可触发动作(isActive) | 布尔 | true=可在时间线上触发，false=仅被动属性 |
| 耐力消耗(staminaCost) | 自然数 | 触发时消耗的耐力（仅 isActive=true 时有效） |
| 触发耗时(actionTime) | 自然数 | 行动间隔，ms（仅 isActive=true 时有效） |
| 伤害(damage) | 整数 | 触发时的伤害（正=伤害，负=恢复，仅 isActive=true） |
| 针对目标(targetFaction) | 枚举 | 友方 / 敌人 / 所有（仅 isActive=true 时有效） |
| 针对类型(targetType) | 枚举 | 近战 / 远程（仅 isActive=true 时有效） |
| 针对顺序(targetOrder) | 字符串 | "从上往下"/"从下往上"（仅 isActive=true 时有效） |
| 优先目标(priorityTarget) | 数字/null | 1/2/3/null（仅 isActive=true 时有效） |
| 回复加成(regenBonus) | 自然数 | 为父实体增加的耐力回复值 |
| 生命加成(hpBonus) | 自然数 | 为父实体增加的生命值 |
| 固定词条(fixedAffixes) | 列表 | 不可拆卸的固有词条 |
| 动态词条槽(dynamicAffixSlots) | 自然数 | 可附加的动态词条数量上限 |
| 物品池前置词条(poolPrerequisite) | 列表 | 解锁条件 |

### 属性显示规则
- **HP**：始终显示
- **耐力上限/耐力回复/负重上限**：仅在拥有 `starter` 词条时显示

## 五、搭配示例

### 示例 1：基础近战 BD
```
出场（第一层）：
  └── 冒险者（starter）  负重: 0/30g
        ├── 短剑（isActive=有, 近战, 耐耗15, 重5g）
        └── 皮甲（isActive=无, 重4g）

总负重: 9/30g ✓, 第一层槽位: 2/2（冒险者占用2）
伤害: 短剑4
HP: 60 + 10(皮甲) = 70
耐力回复: 10/s（皮甲无回复加成）
行动间隔: 1800ms
```

### 示例 2：超重警告 BD
```
冒险者（starter）  负重上限: 30g
  ├── 战锤（isActive=有, 耐耗35, 重15g）
  ├── 盾牌（isActive=无, 重10g）
  └── 锁子甲（isActive=无, 重8g）

总负重: 33/30g ⚠️ 超重！
耐力消耗: 35 × 1.5 = 52（超重惩罚 +50%）
耐力回复: 10/s → 需要 5.2s 恢复 → 严重拖累输出频率！
建议：换掉锁子甲（换皮甲重4g）→ 总负重 29/30g ✓
```

### 示例 3：远程精准打击 BD
```
冒险者（starter）  负重: 0/30g
  ├── 长弓（isActive=有, 远程, 耐耗22, 重8g）
  └── 力量护符（isActive=无, 重1g）

总负重: 9/30g ✓
伤害: 长弓8 + 力量护符3 = 11
长弓从下往上 → 优先击杀敌方后排！
```

### 示例 4：多随从 BD（第5回合）
```
出场（第一层）: 5槽位
  ├── 冒险者（starter, slotCost=2）
  │     ├── 短剑（isActive=有, 近战, 耐耗15）
  │     └── 皮甲（isActive=无）
  ├── 战狼（starter, slotCost=2）
  └── 弓箭手（starter, slotCost=1）

第一层槽位: 2+2+1 = 5/5 ✓（第5回合=5槽位）
三线输出：冒险者+短剑打前排、战狼打前排、弓箭手打第二位
```
