## 核心规则

> **实体即实体。没有硬编码的分类（启动端/装备/武器/防具/饰品/容器只是描述性词条）。**

所有实体拥有相同的属性结构。实体的战斗表现取决于：
- 放在**第一层** + 拥有 `starter` 词条 → 独立参与战斗时间线。
- 放在**第一层** + 无 `starter` 词条 → 木桩（有 HP，可被攻击，不触发动作）。
- 放在**其他实体的槽位中** → 子孙实体，属性叠加给父实体。`isActive=true` 时由父实体触发。

**starter 实体不能放入其他实体的槽位中。**

## 一、统一实体属性定义

所有实体共享以下属性：

| 属性名 | 类型 | 说明 |
|--------|------|------|
| 实体名称 | 字符串 | 唯一名称 |
| 占有槽位(slotCost) | 自然数（含 0） | 在第一层或父实体中占用的槽位；**0 表示不占用** |
| 实体槽位(entitySlots) | 自然数 | 自身可嵌套子实体的数量 |
| 重量(weight) | 自然数 | 重量，单位：克(g) |
| 价值(value) | 自然数 | 购买/出售基准价格 |
| HP | 自然数 | 基础生命值 |
| 耐力上限(maxStamina) | 自然数 | 耐力最大值 |
| 耐力恢复(staminaRegen) | 自然数 | 每秒恢复的耐力值 |
| 生命恢复(hpRegen) | 自然数 | 每秒恢复的生命值 |
| 负重上限(maxLoad) | 自然数 | 可承载子孙实体的最大总重量 |
| 可触发动作(isActive) | 布尔 | true=可在时间线上触发，false=仅被动属性 |
| 耐力消耗(staminaCost) | 自然数 | 触发时消耗的耐力（仅 isActive=true 时有效） |
| 触发耗时(actionTime) | 自然数 | 行动间隔，ms（仅 isActive=true 时有效） |
| 伤害(damage) | 整数 | 触发时的伤害（正=伤害，负=恢复，仅 isActive=true） |
| 统一排序(targetCondition.sortBy) | 字符串 | 从上往下/从下往上/站位1–5/站位中间/hp·stamina 绝对与百分比/random；**缺省 random** |
| 过滤(targetCondition.filterBy) | 字符串数组 | 阵营标签 OR（友方/敌人/自己；**无阵营=空池耗耐**）+ 属性标签 AND |
| 目标数量(targetCount) | 数字或 all | 默认 1；排序后取前 N / 全部（仅 isActive） |
| ~~针对目标 / 类型 / 顺序 / 优先位~~ | — | **已移除配置**；旧 `targetFaction` 读档并入 filterBy；旧顺序字段映射进 sortBy |
| 耐力恢复加成(staminaRegenerationBonus) | 自然数 | 为最外层启动端增加耐力恢复/秒 |
| 耐力加成(staminaBonus) | 自然数 | 为最外层启动端增加耐力上限 |
| 生命恢复加成(hpRegenerationBonus) | 自然数 | 为最外层启动端增加生命恢复/秒 |
| 生命加成(hpBonus) | 自然数 | 为最外层启动端增加生命上限 |
| 负重加成(loadBonus) | 自然数 | 为最外层启动端增加负重上限 |
| 被动加成总开关(hasPassiveBonuses) | 布尔 | false → 引擎跳过该实体全部被动累加；Admin「无」时字段隐藏并清零 |
| 固定词条(fixedAffixes) | 列表 | 不可拆卸的固有词条 |
| 动态词条槽(dynamicAffixSlots) | 自然数 | 可挂载动态词条的槽位上限；已用 = 动态词条 `slotCost` 之和（0 不占） |
| 物品池前置词条(poolPrerequisite) | 列表 | 解锁条件 |

### 属性显示规则
- **HP**：始终显示
- **耐力上限/耐力恢复/HP恢复/负重上限**：仅在拥有 `starter` 词条时显示

## 实体体系

实体通过**固定词条**标记其角色定位，而非硬编码分类：

| 分类词条 | 说明 |
|----------|------|
| `starter` | 第一层战斗单位，独立参与时间线 |
| `weapon_type` | 武器类（isActive=true，可触发动作） |
| `armor_type` | 防具类（被动 HP/耐力加成） |
| `accessory_type` | 饰品（特殊被动加成） |

> 已取消 `follower`（随从）概念。无 `starter` 的第一层实体即为木桩。

实体的战斗角色由以上词条的组合决定，管理员可在制作物品页面自由创建和调整实体模板。

## 搭配原则

- **装备组合**：通过合理搭配武器（输出）、防具（生存）、饰品（功能）来构建 BD
- **负重管理**：子实体总重量不能超过父启动端的**有效负重上限**（`maxLoad + ΣloadBonus`），超重会导致耐力消耗 ×1.5
- **槽位规划**：注意 slotCost（占用父槽位，可为 0）和 entitySlots（自身提供槽位）的平衡；子实体已用槽位 = 直属子实体 `slotCost` 之和
- **第一层槽位**：数量 = `floor((round + 1) / 2)`，详见 [02-名词解释](./02-名词解释.md)
