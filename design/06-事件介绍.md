## 一、通则

### 阶段与抽取

- 设计 **奇数 round** = 探险阶段；每回合默认从事件池抽取 **N = 3** 张事件卡供玩家 **三选一**。
- 每个事件定义 `mustAppearOn`（必出回合）与 `canAppearOn`（可随机回合）。
- **必出优先**：本回合所有 `must` 命中者全部入选；若必出数 > N，仍全部展示（可突破 N）。
- **随机补足**：剩余名额 `max(0, N - 必出数)` 从「`can` 命中且未因 must 入选」者中无放回抽取。
- `canAppearOn` 为空数组时，表示全部奇数探险回合（1..maxRound）；可叠加 `canAppearMinRound` 限制最早可随机回合。
- 同一种事件同回合不重复；must 已蕴含「本回合可展示」。

### 交互通则

- 点选一张事件卡即 **锁定** 本回合唯一事件（`eventStatus: active`）。
- **货架类**（雇佣 / 走私 / 开启路线）：须玩家显式点「**结束事件**」收束；购买后该 SKU 从货架消失，可继续购买其它 SKU。
- **即时类**（打工 / 投资）：点按钮后立即结算并结束（或点「结束事件」放弃）。
- **工匠**：放入实体 → 七选一强化 → 自动结束；亦可点「结束事件」放弃（实体归位）。
- **开战**会收束进行中的事件（货架清空、工匠槽归位）。
- 读档时，当前回合的事件选项与进行中进度须与存档 **完全一致**。

### 事件货架 vs 固定商人

- 事件货架：**不可刷新**；**不可**拖入商人面板半价出售。
- 固定商人：随时可开 Tab；可刷新；可拖入商人面板出售。

| id | 中文名 | must | can | 一句话 |

## 三、逐事件专节

### 雇佣（hire）

**出现规则**

- `mustAppearOn: [1]`：第 1 回合探险 **必出**。
- `canAppearOn: []`：全部奇数探险回合均可随机再抽到。

**玩家流程**

1. 点选「雇佣」进入事件。
2. 浏览货架，拖到 BD 或仓库购买。
3. 点「结束事件」收束。

**奖励与货架**

- 随机 **6** 个可购 **starter** 实体（`isStarter` 且 `value ≤ 本回合 cap` 且在 `itemPool`）。
- 价格 = 物品 **原价**（`getItemTradeValue`）。
- 每种 SKU **仅上架 1 份**；买走后消失；**可连购多种**不同 starter。

**结束与收束**

- 显式「结束事件」或开战收束。

**实现锚点**

- `exploreEvents.ts` · `engine.rollHireOffers()` · `panels.renderActiveEvent`

---

### 走私商人（smuggler）

**出现规则**

- 无 must；全部奇数探险可随机。

**玩家流程**

同雇佣货架流程。

**奖励与货架**

- **6** 实体 + **3** 词条。
- 价值区间：`(本 cap, 下次探险 cap]`，且须在 `itemPool`。
- 价格 = 原价 **× 1.5**（向下取整）。
- 每种 SKU 1 份，买走消失，可任购多种。

**结束与收束**

- 显式「结束事件」或开战收束。

**实现锚点**

- `engine.rollSmugglerOffers()` · `getNextExploreShopCap()`

---

### 工匠（craftsman）

**出现规则**

- 无 must；全部奇数探险可随机。

**玩家流程**

1. 拖入 **1 个实体** 到工匠槽（来自 BD 或仓库）。
2. 七选一永久强化（**七选项始终展示**；未放入实体时点选会提示）。
3. 强化写入 `overrides`，实体归位，事件自动结束。
4. 可拖回 BD/仓库更换槽内实体；点「结束事件」则实体归位并结束。

**奖励与货架**

七选一（写入实体 `overrides`，永久生效）：

| 选项 id | 效果 |
|---------|------|
| `hp` | HP 上限 +100 |
| `hpRegen` | 生命恢复 +2 |
| `staminaRegen` | 耐力恢复 +1 |
| `maxStamina` | 耐力上限 +50 |
| `maxLoad` | 负重上限 +10000 |
| `dynamicAffixSlots` | 动态词条槽 +1 |
| `entitySlots` | 子实体槽 +1 |

**结束与收束**

- 强化成功后自动 `done`；或「结束事件」/开战归位收束。

**实现锚点**

- `engine.moveEntityToCraftsman()` · `applyCraftsmanUpgrade()` · `flushCraftsmanToReturn()` · `pointerDrag` 工匠落点

---

### 打工（work）

**出现规则**

- 无 must；全部奇数探险可随机。

**玩家流程**

- 点「领取报酬」→ 现金 **+20** → 事件结束。
- 亦可只点「结束事件」放弃（无奖励）。

**奖励与货架**

- 无货架；即时现金。

**结束与收束**

- 领取后自动结束。

**实现锚点**

- `engine.doWorkEvent()`

---

### 投资（invest）

**出现规则**

- `canAppearOn: [1, 3, 5, 7]`（仅这些奇数探险回合可随机；无 must）。

**玩家流程**

- 点「投资」→ 扣 **10** 现金 → 备用池 **+20** → 事件结束。

**奖励与货架**

- 备用池在 **下次进入探险** 时随探险金 **静默并入现金**（`grantExploreGold` 结算 `reserveGold`）。

**结束与收束**

- 投资成功后自动结束。

**实现锚点**

- `engine.doInvestEvent()` · `addReserve()` · `grantExploreGold()`

---

### 开启路线（open_path）

**出现规则**

- `mustAppearOn: [3]`：第 **3** 回合探险 **必出**。
- `canAppearMinRound: 5`：第 **1** 回合不出；第 **3** 由 must 保证；第 **5 / 7 / 9 …** 奇数探险可随机再抽到。

**玩家流程**

1. 点选「开启路线」。
2. 浏览全部路线词条，拖到 BD 或仓库购买。
3. 买得起可 **连购多种**；点「结束事件」收束。

**奖励与货架**

- 种子中 `category === 'path'` 的词条 **每种各 1 份**（如：战士、施法、御兽、机械、奴役）。
- **不**按 `itemPool` / `poolPrerequisite` 过滤（专供路线开启）。
- 价格 = **原价**；买走后该条消失；**无**「整场只能买 1 次」限制。

**结束与收束**

- 显式「结束事件」或开战收束。

**实现锚点**

- `exploreEvents` · `engine.rollOpenPathOffers()`
