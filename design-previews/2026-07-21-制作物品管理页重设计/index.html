各方向详细说明

A 命令面板式 ★ 推荐

一句话气质：像 VS Code 命令面板 + Notion 的搜索体验
字体策略：系统无衬线（PingFang SC / Microsoft YaHei）
色彩策略：中性灰底 + #525252 重音色
布局动作：搜索框即命令入口；词条/子实体选择用 Popover 面板（点击展开，搜索即过滤）
记忆点：Ctrl+K 打开命令面板，全程键盘可达
推荐理由：平衡了效率与学习成本。Popover 选择器比 dropdown 高效得多，命令面板入口给高级用户加速路径，同时保留了直观的点击操作。

B 结构化表单式

一句话气质：像专业的后台管理系统（Stripe Dashboard）
字体策略：系统无衬线，暖灰调
色彩策略：暖灰底（Stone 系）+ 绿色强调（#166534）
布局动作：固定词条用双面板 Transfer List（左可用 / 右已选），直观清晰
记忆点：Transfer List 的双面板结构，一眼看清已选和可选

C 暗色工作台

一句话气质：像 Cursor / VS Code 的暗色 IDE 面板
字体策略：系统无衬线，深色底高对比
色彩策略：深色底 #1a1a1a + 浅灰面板 #262626
布局动作：Token Input 替代 dropdown（输入即搜索，回车即添加）；Ctrl+K 命令面板
记忆点：键盘驱动的暗色专业工作台，长时间使用不刺眼

D 分栏式

一句话气质：像 Xcode / Unity Inspector 的三栏开发工具
字体策略：系统无衬线，紧凑的信息密度
色彩策略：浅灰底 + 黑色重音（#1a1a1a）
布局动作：左侧树形导航 + 中间编辑区 + 右侧属性检查器（词条/子实体拖拽管理）
记忆点：三栏 IDE 布局，属性检查器实时反映选中实体的配置
所有方向共通优化：
① 左侧面板统一为 搜索 → 筛选 Chip → 新增按钮（加大） → 全选/已选 → 列表
② "启动端字段"重命名为"战斗属性"
③ 槽位计数放在对应编辑区标题旁（如"动态词条 · 已用 2/3"）
④ 槽位=0 时自动隐藏编辑区
⑤ 子实体改为纯引用（只显示名称+类别，不内联编辑字段）
⑥ 分类管理按钮移到词条 Tab 的新增按钮上方
