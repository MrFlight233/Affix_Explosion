方向说明（样机区分开）

A · 印刷台账四区

气质：像会计报表 / 印刷规则线。

字体：IBM Plex Mono 主导。

布局：保留经典四区，精修密度与顶栏。

互斥约束：必须亮色印刷质感。

代价：与模拟战工具风仍分裂；结算/历史需另套「报表附页」。

B · 工作台统一（推荐）

气质：像 Linear / Notion 生产力工具，与现有模拟战 07-模拟对战设计系统.md 同源。

字体：IBM Plex Sans + 系统中文栈。

布局：顶 HUD · 左 BD 树 · 右情景 Tab · 底情境坞（出售/阶段动作）。

互斥约束：必须像高效专业工具而非游戏皮肤。

推荐理由：正式局缺口页（结束态/结算/历史/异常）最容易用同一套组件长出来；开发与学习成本最低。

C · 战报印刷物

气质：像旧报纸战报 / 桌游说明书。

字体：Source Serif 4 / Literata 刊头 + 正文衬线。

布局：整页「报面」+ 右缘批注栏；拖拽权重下降、阅读权重上升。

互斥约束：必须借非数字时代视觉语言。

代价：拖拽组 BD 效率可能变差；与 Admin/模拟战反差大。

D · 暗色对阵台

气质：像 IDE / 对战观战台。

字体：IBM Plex Mono。

布局：我方 | 日志/结束态 | 敌方；探险为次级模式。

互斥约束：必须暗色高密度、战斗优先。

代价：违背原「白底黑字」总纲，需正式修订视觉原则；探险构筑空间被挤压。

也可混搭：例如「要 B 的壳 + D 的战斗三栏 + A 的数字台账感」。在确认弹层建议框或对话里说明即可。
