# 效果库独立化 · 完整实现计划

> 日期：2026-08-19  
> 状态：已实现  
> 目标：效果库一等公民 + 实体/词条主动被动通道；迁完删旧写法；删除被动加武器伤害  
> 与 `design/09-效果介绍.md` 同步

## 一、定位与 Context

### 现状

- 命中效果、被动效果内联在实体/词条 JSON（`onHitEffects` / `passiveEffects`）
- 无独立效果目录；制作时每件物品各自配管道
- 设计文档仍描述已死的「被动加武器伤害」

### 期望

- 独立效果库；实体/词条只保留主动/被动通道（何时、打谁、引用哪些、填参）+ 被动总开关
- 旧内联迁库后删除；上线清空存档/历史/匹配池
- 词条原「效果」文案改称「描述」

### 原因

大型机制更新：配方复用、通道职责清晰、避免复制两套几乎相同的效果条目。

### 不介入

- 效果不当可买第三种物品
- 代币/光环/邻接 BUFF（仅 design/09 预留）
- 重写 targeting_modifier / 战斗时间线

## 二、核心抽象与规则

见定稿拷问表（doc 与 plan 一致）：

- 一套目录 + `allowActive` / `allowPassive`
- 打谁在通道；结算落点在配方（挂载可覆写）
- 挂载主要改数字；先建再挂；可读名优先
- 重复挂载按配方合并；流血=持续+跳伤可配
- 有引用禁删；大改警告

## 三、数据协议

```typescript
interface EffectDef {
  id: string;
  name: string;
  description?: string;
  allowActive: boolean;
  allowPassive: boolean;
  kind: 'instant' | 'duration';
  stat: string;
  op: 'gain' | 'loss' | 'set';
  defaultParams: { amount?: number; percent?: number };
  defaultDurationMs?: number;
  defaultTickIntervalMs?: number;
  defaultDisplayName?: string;
  defaultApplyTo?: Array<'starter' | 'actionOwner' | 'target'>;
  paramSchema?: string[];
  category?: string;
}

interface EffectBinding {
  effectId: string;
  params?: Partial<{
    amount: number; percent: number;
    durationMs: number; tickIntervalMs: number;
    displayName: string;
  }>;
  applyTo?: Array<'starter' | 'actionOwner' | 'target'>;
  condition?: SubtreeCondition;
  order?: number;
}

interface ActiveChannel {
  enabled?: boolean;
  actionTime?: number;
  staminaCost?: number;
  targetCondition?: TargetCondition;
  targetCount?: number | 'all';
  effectBindings: EffectBinding[];
}

interface PassiveChannel {
  enabled: boolean; // hasPassiveBonuses
  targetCondition?: TargetCondition;
  targetCount?: number | 'all';
  effectBindings: EffectBinding[];
}
```
