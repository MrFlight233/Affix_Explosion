# 统一实体模型术语 + 显示逻辑修正

## 背景

项目已从旧的"三种互斥类型"重构为统一实体模型。同一实体可同时拥有：启动端词条、可触发动作(isActive=true)、被动加成。

但大量代码注释和 UI 显示逻辑仍使用旧模式的互斥三元：`isStarter ? '启动端' : isActive ? '主动装备' : '被动装备'`。

## 修正文件

| 文件 | 改动数 | 类型 |
|------|--------|------|
| `project/shared/types.ts` | 3 | 注释修正 |
| `project/client/src/game/data.ts` | 4 | 注释修正 + 与 types.ts 同步 |
| `project/client/src/game/engine.ts` | 1 | 注释修正 |
| `project/client/src/ui/tooltip.ts` | 3 | 标签 + 显示条件 |
| `project/client/src/ui/sim-battle.ts` | 5 | 标签 + 悬浮窗 + 条件 |
| `project/client/src/ui/panels.ts` | 2 | 注释修正 |
| `project/client/src/main.ts` | 4 | 标签 + 过滤器 |
| `design/05-战斗系统.md` | 1 | 术语修正 |

## 核心原则

- 字段注释用条件式描述（isActive=true 时…），不用类型式描述（"主动装备: …"）
- UI 标签按实际条件独立显示多个标签，不使用互斥三元
- 显示逻辑不因实体是启动端就排除其主动/被动信息
