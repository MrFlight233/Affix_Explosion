# 九出十三归 / 路线商人 / 打工投资调参

> 日期：2026-08-17  
> 状态：已实现  
> 与 `design/06-事件介绍.md`、`design/02-名词解释.md` 同步

## 修改点 1：新事件九出十三归（`nine_thirteen`）

### 现状

无「先拿现金、备用池负债」事件；现有投资点一次即 `completeEvent`。

### 期望

- 名：九出十三归；id：`nine_thirteen`
- 出现：无 must；`canAppearOn: [1, 3, 5, 7]`
- 同次事件内可连点：每次现金 +9（计入 `totalGoldGained`）+ 备用池 −13；不自动结束
- 点「结束事件」收束

### 原因

允许玩家在同一次事件里连续借贷，自己权衡现金与负债。

### 实现

- `project/client/src/game/exploreEvents.ts`：defs + 描述
- `project/client/src/game/engine.ts`：`doNineThirteenEvent()` 只改资金，不调用 `completeEvent`
- `project/client/src/ui/panels.ts`：可反复点 +「结束事件」
- 单测：连点 2 次 → gold +18、reserve −26，`eventStatus` 仍 `active`
- `design/06` 专节 + 一览；`design/02` 摘要

## 修改点 2：新事件路线商人（`path_merchant`）

### 现状

货架类：雇佣 / 走私 / 开启路线。走私按价值区间 ×1.5；开启路线为 path 词条各 1（不重复、不经池）。

### 期望

- 名：路线商人；id：`path_merchant`
- 出现：`canAppearOn: [5, 7, 9]`
- 货架：路线物品（`itemPool` 且 `poolPrerequisite` 含 path 词条 id）有放回随机 6 实体 + 3 词条；原价；买走该 instance 消失
- 候选为空则该侧上架 0

### 原因

中后期原价路线补给；抽样默认可重复，与开启路线「每样一个」区分。

### 实现

- `exploreEvents.ts`：defs + 路线过滤辅助
- `engine.ts`：`rollPathMerchantOffers()`；`beginEvent` 分支
- UI 复用 `eventOffers` 拖拽购
- 单测：仅 5/7/9；有放回可同 defId 多份
- `design/06` / `02` 同步

## 修改点 3：打工调参（同次仅一次，不排出池）

### 现状

`doWorkEvent`：+20；领后 `completeEvent`。

### 期望

- 金额 +10；同次只能领一次（领后 `completeEvent`）
- 不排出本局事件池，后续探险仍可再遇

### 原因

单次事件内防连刷；跨回合仍可再遇。

### 实现

- `doWorkEvent`：+10 + `recordGoldGained(10)` + `completeEvent`
- panels / `getExploreEventDesc` 文案
- `design/06` / `02` 同步

## 修改点 4：投资调参（同次可连点）

### 现状

付 10、池 +20；点一次即 `completeEvent`；`canAppearOn: [1,3,5,7]`。

### 期望

- 付 10、备用池 +15；同次可连点；不自动结束；「结束事件」收束

### 原因

与九出十三归同为可连点资金玩法；略降单次回报。

### 实现

- `doInvestEvent`：改数值；去掉 `completeEvent`
- panels：可连点 + 结束事件
- 单测：连点 2 次池 +30、金 −20，状态仍 `active`
- `design/06` / `02` 同步
