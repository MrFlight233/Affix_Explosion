# 物品价值：本体与总价值

> 计划文档：供其它智能体执行/对照验收。

## 两套口径

| 名称 | 定义 | 用途 |
|------|------|------|
| **本体价值** `baseValue` | 模板字段：实体 `value`，词条 `abs(costValue)` | 商人货架准入（价值上限）、事件随机价值区间、管理端编辑字段 |
| **总价值** `tradeValue`（设计「动态价值」） | 实例价值树合计；模板按 `createItem` 默认交付结构合计 | 买/卖结算、商店标价、卡片/悬停、全物品池列表栏 |

## 公式

```
getItemTradeValue(item):
  affix → abs(costValue)
  entity → value + Σ固定词条(abs) + Σ children 递归
  固定词条：overrides.fixedAffixes ?? def.fixedAffixes

getDefPackageTradeValue(entityDef):
  对齐 createItem：本体 + 固定 + 预装动态词条 + defaultChildren（含 spec）递归

买价 = tradeValue（或事件 priceOverride）
卖价 = floor(tradeValue / 2)
```

商人上限仍按**本体**过滤。
