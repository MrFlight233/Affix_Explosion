# 制作物品：战斗属性区可折叠

> 日期：2026-08-06  
> 状态：已实现

## 定稿

实体表单「战斗属性」分区可折叠；当 HP / 耐力上限 / 耐力恢复 / HP恢复 / 负重上限 **全部为 0** 时默认折叠，否则默认展开。点击标题切换。

## 落点

- `project/client/src/ui/admin.ts` — `buildEntityForm` + `bindEntityFormEvents`
- `project/client/styles/global.css` — `.adm-fold-h` / `.adm-fold-body`
- `design/07-模拟对战设计系统.md` 实体表单分区说明

## 手测

1. 新建实体（字段默认 0）→ 战斗属性默认折叠，点标题可展开
2. 打开有非零战斗属性的 starter → 默认展开
3. 折叠态下保存仍写入表单值（字段在 DOM 中，仅隐藏）
