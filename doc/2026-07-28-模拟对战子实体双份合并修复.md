# 模拟对战子实体双份合并修复

> 日期：2026-07-28  
> 状态：已实现

## 问题

卸下人类默认拳头后挂上匕首+一拳，开战预览/战斗仍为 1 匕首 + 3 拳头。并非读了旧 BD，而是 `DeploySlot` 数据重复。

## 根因

1. 第一层入槽时 `children: [...(entity.children||[])]` 浅拷贝默认子实体到 `slot.children`
2. UI 只编辑 `entity.children`；卸下只改前者，`slot.children` 残留
3. `calculateCombatSnapshots` 合并两边 → 多出残留拳头

## 修复

- 入槽：`{ entity, children: [] }`，禁止拷贝
- `ingestSlotsForSim`：抽池时把 `slot.children` 合并进 `entity.children` 后清空
- 开战/预览前：`sanitizeSimSlotsBeforeCombat` 仅清空 `slot.children`（以 UI 的 entity 树为准，清幽灵）
- 删除/抽出：从 entity 树与 `slot.children` 双清
