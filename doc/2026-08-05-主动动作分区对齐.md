## 定稿

1. Admin / 物品池一级分区：**主动动作**（原「可触发动作」）；总开关文案 **主动动作**（有/无）；`isActive` 字段不变。
2. Admin 二级 `adm-section-title`：**主动消耗** → **主动目标** → **主动效果**。
3. 卡面 / 悬浮：仅一级块「主动动作」；**不加**副标题；行标签区分——消耗行 `耐力`/`间隔`，`主动目标:`，引导行 `主动效果` 后接效果行；被动对称 `被动目标:` + 引导行 `被动效果`。
