# 去除战斗预览功能

> 日期：2026-07-29  
> 状态：已实现  
> 取代：[`2026-07-28-统一战斗预览与播放控制.md`](./2026-07-28-统一战斗预览与播放控制.md) 中「预览」部分  
> 与 `design/05-战斗系统.md` §1.0 同步

## 目标

- 正式战、模拟战均不再弹出战斗预览面板。
- 点击「开始战斗 / 开始模拟战斗」后直接开战（空池正式战仍直接结算获胜）。
- 完整删除预览模块与样式，不留死代码。
- **保留**：战斗中暂停/倍速（`playbackControls`）、正式战「先 `prepareOfficialBattle` 再开战且不二次抽池」。

## 选型

| 方案 | 结论 |
|------|------|
| 仅短路调用、保留文件 | 弃用：会留下无引用模块与 CSS |
| **完整删除 `combatPreview.ts` + CSS + 调用点** | **已采用** |

## 实现要点

### `project/client/src/ui/panels.ts`

- `startCombat`：`prepareOfficialBattle` 成功后直接 `_doStartCombat`，不再 `showCombatPreview`。
- 删除 `import { showCombatPreview }` 及预览用的 `calculateCombatSnapshots`。
- 保留 `pendingEnemySlots` / `pendingAutoWin` 与 `_doStartCombat`。

### `project/client/src/ui/sim-battle.ts`

- 删除 `showSimBattlePreview` 及 `showCombatPreview` import。
- `startSimBattle` 校验通过后直接 `_doStartSimBattle`。
- 保留 `_doStartSimBattle` 内 `sanitizeSimSlotsBeforeCombat`。

### 删除模块与样式

- 删除 `project/client/src/ui/combatPreview.ts`。
- `project/client/styles/global.css`：删除 `#combat-preview*` / `.cp-*` / `#cp-btn-*` 段；保留 `.sb-speed-group` / `#hud-playback`。

### `project/client/src/game/engine.ts`

- 仅更新注释措辞（匹配后开战 / 避免二次抽池）；不删 API。

### `design/05-战斗系统.md` §1.0

- 去掉快照预览步骤；正式战匹配后立即开战/结算；模拟战仅共用播放控件。

## 验收用例

1. [x] 正式战点「开始战斗」：匹配成功后直接进入 `phase=2`，无预览弹层（代码路径已短路）
2. [x] 正式战空池：匹配后直接获胜结算（`_doStartCombat` → `settleOfficialAutoWin`）
3. [x] 正式战匹配失败：toast，仍停留部署阶段
4. [x] 模拟战点「开始模拟战斗」：直接进入战斗视图
5. [x] 战斗中暂停/倍速仍保留（`playbackControls` 未改）
6. [x] 仓库无 `combatPreview` / `#combat-preview` 残留；design / doc 已同步

## 明确不做

- 不改战斗演算、`calculateCombatSnapshots`、对战池上传/抽取
- 不删 `playbackControls` 及战斗中 HUD 暂停/倍速
- 不批量改写其它历史 `doc/` 正文
