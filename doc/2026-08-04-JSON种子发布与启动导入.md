# JSON 种子发布与启动导入

> 日期：2026-08-04  
> 状态：已实现  
> 与 `CLAUDE.md` AI 限制、`project/README.md` 同步

## 目标

用 Git 跟踪**模板数据**（实体 / 词条 / 分类），换机器拉取后空库可自动灌入同一套数据。运行时 `game.db` 仍不入库。

## 选型

| 方案 | 结论 |
|------|------|
| 直接提交 `game.db` | 否（WAL、二进制冲突、易混入本地状态） |
| JSON 种子 + 显式发布 | **采用**：Admin「发布种子」+ CLI `npm run seed:publish` |
| 每次 Admin 保存自动写种子 | 否（diff 吵、半成品易入库） |

## 行为约定

1. **种子目录**：`project/server/data/seed/`
   - `entities.json` / `affixes.json` / `categories.json`
   - `meta.json`：`exported_at`、`version`、各表条数
2. **启动导入**：建表后若 `entities` 与 `affixes` **均为空**，则从种子写入 DB，再加载缓存；已有模板则跳过（不覆盖本地）。
3. **发布种子**：把当前缓存中的模板写出到种子目录（覆盖）。不写 users/saves/battle_pool/run_history。
4. **AI 提交前**：若本次提交包含 `data/seed/`，必须先跑 `npm run seed:publish`（见 `CLAUDE.md`），不得假设用户已点按钮。

## 实现要点

| 路径 | 改动 |
|------|------|
| `project/server/src/db/seedData.ts` | `importSeedIfEmpty` / `publishSeed` / `getSeedStatus` |
| `project/server/src/db/schema.ts` | `initDB` 中建表后、`load` 前调用 `importSeedIfEmpty` |
| `project/server/src/db/index.ts` | 导出 seedData API |
| `project/server/src/routes/admin.ts` | `POST /seed/publish`、`GET /seed/status` |
| `project/server/src/scripts/publish-seed.ts` | CLI 入口 |
| `project/server/package.json` | `"seed:publish": "tsx src/scripts/publish-seed.ts"` |
| `project/client/src/api/client.ts` | `admin.publishSeed` / `admin.seedStatus` |
| `project/client/src/ui/admin.ts` | 顶栏「发布种子」按钮 + 确认 |
| `.gitignore` | 继续忽略 `*.db*`；**不**忽略 `data/seed/` |
| `CLAUDE.md` | AI 限制：提交种子前必须主动导出 |
| `project/README.md` | 种子说明替换旧 `game_data.json` |

## 验收

- [ ] 空库启动且存在种子 → 日志显示导入条数，缓存非 0
- [ ] 已有实体/词条启动 → 日志「跳过种子导入」，数据不变
- [ ] Admin「发布种子」或 `npm run seed:publish` → `data/seed/*.json` 更新
- [ ] `git status` 可看到种子文件变更；`*.db` 仍被忽略

## 明确不做

- 不把存档 / 对战池 / 用户表写入种子
- 不在每次 Admin 保存时自动写种子
- 不覆盖非空本地库
