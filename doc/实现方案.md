## 三、数据库设计

### 3.1 表结构

```sql
-- 玩家账号
CREATE TABLE users (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    username    TEXT    NOT NULL UNIQUE,
    password    TEXT    NOT NULL,          -- bcrypt hash
    created_at  TEXT    NOT NULL DEFAULT (datetime('now'))
);

-- 存档数据
CREATE TABLE saves (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id     INTEGER NOT NULL REFERENCES users(id),
    slot        INTEGER NOT NULL DEFAULT 1,  -- 存档槽位 1~3
    data_json   TEXT    NOT NULL,            -- 完整游戏状态 JSON
    updated_at  TEXT    NOT NULL DEFAULT (datetime('now')),
    UNIQUE(user_id, slot)
);

-- 实体定义（后台管理用，也可直接 hardcode 在 shared/types 中）
CREATE TABLE entities (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT    NOT NULL UNIQUE,     -- 唯一名称
    category    TEXT    NOT NULL,            -- 角色/武器/防具/饰品/随从/容器
    stats_json  TEXT    NOT NULL,            -- 完整属性 JSON
    version     INTEGER NOT NULL DEFAULT 1   -- 数据版本号
);

-- 词条定义
CREATE TABLE affixes (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT    NOT NULL UNIQUE,
    category    TEXT    NOT NULL,            -- 属性/行动/伤害/防御/耐力/负重/容器/限制/特殊
    stats_json  TEXT    NOT NULL,
    version     INTEGER NOT NULL DEFAULT 1
);

-- 战斗池（异步 PvP）
CREATE TABLE battle_pool (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id     INTEGER NOT NULL REFERENCES users(id),
    floor       INTEGER NOT NULL,           -- 层数
    round       INTEGER NOT NULL,           -- 轮数
    bd_json     TEXT    NOT NULL,            -- 出场 BD 完整 JSON
    power_score INTEGER NOT NULL DEFAULT 0,  -- 战力评分（用于匹配）
    uploaded_at TEXT    NOT NULL DEFAULT (datetime('now'))
);

-- 战斗记录
CREATE TABLE battle_logs (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    attacker_id     INTEGER NOT NULL REFERENCES users(id),
    defender_bd_id  INTEGER NOT NULL REFERENCES battle_pool(id),
    result          TEXT    NOT NULL,        -- 'win' / 'lose'
    log_json        TEXT    NOT NULL,        -- 战斗日志
    created_at      TEXT    NOT NULL DEFAULT (datetime('now'))
);
```

### 3.2 初始数据

`entities` 和 `affixes` 表初始写入设计文档中定义的全部数据。同时也在 `shared/types/` 中维护一份 TypeScript 常量作为 fallback（后端不可用时前端可离线使用）。

### 9.1 拖拽系统

```
HTML5 Drag & Drop 事件：
  dragstart → 记录被拖拽物品的 ID 和来源面板
  dragover  → 判断目标区域是否可放置（验证规则）

```

来源/目标组合：
| 来源 | 目标 | 操作 |
|------|------|------|
| 出场面板 | 仓库面板 | 卸下物品 |
| 仓库面板 | 出场面板 | 装备物品 |
| 商店面板 | 出场面板 | 购买物品（扣金币） |
| 出场/仓库 | 出售面板 | 出售物品（加金币） |

### 9.2 战斗时间线实现

```
使用优先队列（最小堆）存储行动事件：

class CombatTimeline {
  heap: MinHeap<{ time: number, unit: CombatUnit }>;

  nextEvent(): { time, unit } | null;
  schedule(unit: CombatUnit, baseTime: number): void;

  // 主循环
  async run(): Promise<CombatResult> {
    let currentTime = 0;
    while (!this.isOver()) {
      const event = this.nextEvent();
      currentTime = event.time;

      // 恢复耐力
      this.regenAllStamina(event.time);

      // 尝试行动（耐力检查）
      const canAct = this.checkStamina(event.unit);
      if (canAct) {
        this.executeAction(event.unit, currentTime);
      } else {
        // 搁置，等待耐力恢复后立即触发
        this.scheduleWhenStaminaReady(event.unit, currentTime);
      }

      // 注册下一次行动
      this.schedule(event.unit, currentTime + event.unit.dynamicActionTime);
    }
    return this.buildResult();
  }
}
```

### 9.3 实体嵌套验证

```typescript
function canNest(parent: Entity, child: Entity, allDeployed: DeploySlot[]): boolean {
  // 规则 1：可行动实体不能放入任何实体中
  if (isActionable(child) && '可行动' in child.fixedAffixes) {
    return false;  // 可行动实体只能第一层级
  }

  // 规则 2：可行动的父实体不能包含可行动的子实体
  if (isActionable(parent) && isActionable(child)) {
    return false;
  }

  // 规则 3：递归检查——可行动实体不下放到子孙层级
  if (hasActionableAncestor(allDeployed, parent)) {
    return false;
  }

  // 规则 4：槽位检查
  if (parent.entitySlots < child.slotCost) {
    return false;
  }

  return true;
}
```

### 9.4 战力评分（战斗池匹配用）

```typescript
function calculatePowerScore(bd: DeploySlot[]): number {
  let score = 0;
  for (const slot of bd) {
    score += slot.entity.baseDamage * 10;
    score += slot.entity.totalArmor * 5;
    score += slot.entity.maxStamina;
    score += slot.entity.staminaRegen * 2;
    score += slot.entity.totalHp * 2;
    for (const child of slot.children) {
      if (isActiveWeapon(child)) {
        score += child.damageBonus * 8;
        score += child.staminaCost * -0.5;  // 高消耗稍微减分
      } else {
        score += child.armorBonus * 5;
        score += child.hpBonus * 2;
      }
    }
  }
  return Math.round(score);
}
```
