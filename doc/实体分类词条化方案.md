## 五、实施步骤

### Step 1: 新增分类词条 + 新词条（data.ts / server data.ts）

- AFFIX_DEFS 新增类别 `'类别'` 
- 新增 4 个分类词条 + 50 个新词条，总计 85 个
- ENTITY_DEFS 新增 4 个默认装备实体

### Step 2: EntityDef 新增 defaultChildren（data.ts / shared/types.ts）

```typescript
defaultChildren?: string[];  // 创建实体时自动生成的子实体 defId
```

### Step 3: 所有实体更新 fixedAffixes + 删除 category（data.ts / server）

- 70 实体添加对应分类词条
- 4 新增实体同理
- 删除所有 74 个实体定义中的 category 字段

### Step 4: createItem 适配 defaultChildren（engine.ts）

```typescript
createItem(defId, type) {
  const item = { instanceId: genId(), defId, type };
  if (type === 'entity') {
    const def = getEntityDef(defId);
    if (def?.defaultChildren) {
      item.children = def.defaultChildren.map(cid => this.createItem(cid, 'entity'));
    }
  }
  return item;
}
```
