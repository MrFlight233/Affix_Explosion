# 卡面折叠 / 悬浮窗缩进 / 隐藏池前置

> 日期：2026-08-13  
> 状态：已实现

## 目标

卡面默认收起战斗修饰与固定词条；悬浮窗用缩进表达子实体嵌套；玩家侧 UI 一律不展示池前置（词条 `prerequisite` 仍展示）。

---

## 修改点 1：战斗修饰区默认折叠

### 现状

卡面有战斗修饰时整块展开，列表较长。

### 期望

默认折叠，标题为「战斗修饰 (N) 展开/收起」；折叠时不再单独显示「N 条」。

### 原因

战斗中修饰行多，默认展开占位；需要时再展开。条数放进标题更紧凑。

### 实现

- `project/client/src/ui/build/types.ts`：`expandedCombatModBlocks`（集合内=展开，缺省折叠）
- `project/client/src/ui/build/entityCard.ts`：标题 `战斗修饰 (${n})` + 展开/收起；折叠无额外 hint 行
- `sim-battle.ts` / `officialExplore.ts` / `officialCombat.ts`：绑定 toggle

---

## 修改点 1b：实体折叠摘要不展示分类

### 现状

无主动/被动摘要的实体折叠行带 `getEntityCategory`（如「施法 / 物品 / 扩容」）。

### 期望

仅名称与重量等关键信息，例如「小背包 重:1kg」。

### 原因

折叠行只要识别物品，分类可在展开或 tip 中看。

### 实现

- `renderCardKeyInfo` 兜底分支去掉 `${cat}`

---

## 修改点 2：固定词条区默认折叠

### 现状

固定词条默认展开（或旧语义 `collapsedFixedAffixRows` 集合内=折叠）。

### 期望

默认折叠；展开后逐条显示。折叠时标题旁可带名称摘要。

### 原因

与战斗修饰一致，减少默认噪音。

### 实现

- `collapsedFixedAffixRows` → `expandedFixedAffixRows`（集合内=展开）
- `entityCard.ts` 固定词条块读 `expandedFixedAffixRows`
- 模拟战 / 正式探险 / 正式战斗 toggle 同步

---

## 修改点 3：悬浮窗子实体缩进按深度递增

### 现状

`renderTooltipTree` 子实体行：`depth === 0 ? tipIndent(1) : tipIndent(depth)`，深度≥1 与第一层同为 12px，看不出孙实体。

### 期望

第 n 层子实体 `margin-left: (n) * 12px`（实现为 `tipIndent(depth + 1)`）。

### 原因

缩进是嵌套关系的直观线索。

### 实现

- `project/client/src/ui/build/simTooltip.ts`：子实体行统一 `tipIndent(depth + 1)`；嵌套词条行用 `tipIndent(depth + 1)` 略深于所属实体名

---

## 修改点 4：池前置统统不显示（词条前置保留）

### 现状

卡面/tip/物品池详情会展示实体或词条的 `poolPrerequisite`。

### 期望

玩家侧不显示任何池前置；词条 `prerequisite`（放置前置）照常显示。Admin 编辑区不受影响。

### 原因

池前置只影响解锁，对构筑阅读干扰大；放置前置仍需可见。

### 实现

- `entityCard.ts`：词条卡只显示 `prerequisite`（此前已去掉池前置）
- `simTooltip.ts`：实体 tip / 词条 tip 去掉 `poolPrerequisite`
- `tooltip.ts`：同上
- `itemPool.ts`：实体/词条详情去掉池前置区块
