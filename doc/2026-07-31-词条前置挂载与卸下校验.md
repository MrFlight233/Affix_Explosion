# 词条前置挂载与卸下校验

## 规则

- 挂载：`AffixDef.prerequisite` 须被目标实体已有词条满足（固定 + 动态）。
- 卸下：其它动态词条仍依赖被卸 `defId` 则拒绝并列出依赖者。
- 范围：模拟战 BD、正式局 BD/仓库相关拖放；Admin 制作物品不校验。

## 实现

| 文件 | 内容 |
|------|------|
| `game/data.ts` | `getEntityOwnedAffixIds` / `canMountAffix` / `canRemoveAffix` / `findParentInTree` |
| `game/engine.ts` | `moveToDeploy` affix、`moveToWarehouse`、`sellItem` |
| `ui/officialExplore.ts` | 处理卸下/出售错误串 |
| `ui/sim-battle.ts` | `commitPointerDrag` 挂载与卸下 |

## 验收

- 无前置时挂依赖词条 → toast 需要前置
- 有固定或动态前置后可挂
- 卸被依赖词条 → toast 不可移除并点名依赖者
