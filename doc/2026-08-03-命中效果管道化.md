# 命中效果管道化

日期：2026-08-03  
供其它智能体执行/核对。

## 目标

- 废除主动动作独立 `damage` 结算；伤害/回复等一律走 `onHitEffects` 数值管道。
- 实体与词条共用同一 `OnHitEffect` 结构。
- 去掉被动 `damageBonus`。
- 挂载范围：武器本地 / 启动端覆盖其全部主动。
- `applyTo` 多选；百分比向下取整。

## 效果结构

```ts
{
  displayName: string;
  stat: 'hp' | 'stamina';
  op: 'gain' | 'loss' | 'set';
  params: { amount?: number; percent?: number };
  applyTo?: ('starter' | 'actionOwner' | 'target')[]; // 缺省 target
}
```

`value = floor(hitMagnitude * percent/100) + amount`

## 关键文件

- `project/shared/hitEffectUtil.ts` — 规范化/迁移/展示
- `project/client/src/game/battle/onhit.ts` — 管道结算
- `project/client/src/game/battle/simulator.ts` — 读武器 `onHitEffects`
- `project/client/src/game/engine.ts` — 按宿主拼装最终列表
- Admin：`adminHitEffects.ts` + `admin.ts`
- DB：`entities.on_hit_effects`；seed 迁移旧 damage / 词条 damage_bonus

## 迁移

- 实体 `damage` → hp loss/gain 效果，并清零 damage
- 词条 `damage_bonus` → 一条伤害效果，清零 bonus
- 旧 `type: life_steal|...` 读档规范化

## 非目标

- 非数值效果、DROP damage_bonus 列、onKill
