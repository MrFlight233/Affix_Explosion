# 移除词条废弃字段 value（数值）

> 日期：2026-07-28  
> 状态：已实现  
> 说明：词条 `value` 已不再参与战斗；效果改由被动结构化字段等承担

## 目标

从类型、Admin、展示与读写路径中移除词条 `AffixDef.value` / DB `affixes.value`（表单「数值」）。**不改**实体 `EntityDef.value`（价值）。

## 选型或根因

| 项 | 现状 | 结论 |
|----|------|------|
| 战斗 | 不用 `affix.value`，用 `damageBonus` 等 | 可删 |
| UI | Admin 可编；sim-battle/main 仅展示 | 一并删 |
| 价值 | `costValue` | 保留 |

## 实现要点

- `data.ts`：`AffixDef` 去掉 `value`
- `schema.ts` / `seed.ts` CREATE：新库建表不再含 `value`；**不做 DROP 迁移**（旧库残留列可忽略）
- `cache.ts` / `affixRepo.ts`：读写去掉 value
- `admin.ts` / `sim-battle.ts` / `main.ts`：去掉数值表单与展示
- `design/04`、`design/05`：去掉初始/动态数值；strength 改为 damageBonus

## 验收

- [x] Admin 词条无「数值」字段；保存/导入不依赖 value
- [x] 客户端词条类型无 value；展示不再出现「数值」
- [x] 实体价值 `value` 仍可用
- [x] design 04/05 已同步
- [x] 无 affixes.value 的 DROP 迁移
