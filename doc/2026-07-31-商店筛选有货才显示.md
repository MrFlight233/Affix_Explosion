# 商店筛选：仅显示货架有货的类型

> 日期：2026-07-31  
> 状态：已实现  
> 相关：[`doc/2026-07-30-分类筛选显示开关.md`](./2026-07-30-分类筛选显示开关.md)

## 目标

正式局商店筛选 Chip 在 `showInFilter` 之外，再按当前商人货架（`catalogItems`）实际有货裁剪：

- 实体：货架无「饰品」则不显示「饰品」Chip
- 词条：货架无某分类词条则不显示该 Chip
- 「全部实体」「全部词条」始终保留
- 判定基于货架原列表（搜索/已选分类之前）

不影响全物品池、模拟对战、管理端。

## 实现

### [`poolList.ts`](project/client/src/ui/build/poolList.ts)

`renderPoolFiltersHtml(state, opts)` 扩展：

```ts
opts?: {
  forShop?: boolean;
  catalogEntities?: EntityDef[];
  catalogAffixes?: AffixDef[];
}
```

`forShop` 且传入 catalog 时：

- 实体 Chip：`getEntityCategoryFilters()` 保留 `all`，其余仅保留货架实体 `getEntityCategory(e)` 命中的名称
- 词条 Chip：`getShopAffixFilterCategories()` 再过滤为货架词条 `a.category` 出现过的 id

### [`officialExplore.ts`](project/client/src/ui/officialExplore.ts)

`renderOfficialShopHtml`：`catalogDefs(ctx)` → 传入 `catalogEntities` / `catalogAffixes`；若当前 `entityCatFilter` / `affixCatFilter` 已不可见则回退 `'all'`。

## 验收

- [x] 货架无饰品时无「饰品」Chip；有则有
- [x] 货架无某词条分类时无该 Chip；`showInFilter=false` 仍隐藏
- [x] 选中分类售空/换货后筛选回退「全部」
- [x] 模拟战 Chip 不受影响
