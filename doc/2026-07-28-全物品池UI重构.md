# 全物品池 UI 重构

> 日期：2026-07-28  
> 状态：已实现  
> 与 `design/DESIGN.md` 同步  
> 样机：`design-previews/2026-07-28-全物品池UI重构/index.html`

## 目标

将启动页「全物品池」重构为与制作物品管理页同款的工作风两栏只读浏览器：分区/字段/显隐镜像 `buildEntityForm` / `buildAffixForm`；词条与子实体一行一项；固定词条、预装动态词条、子实体区可折叠。

## 实现要点

### `project/client/src/ui/itemPool.ts`

- 导出 `showFullItemPool(onBack)`
- `#ip-page`：顶栏 Tab 实体/词条；左栏 Chip + Ctrl+K 搜索 + 列表；右栏只读分区详情
- 折叠状态按 `选中id + 区块` 记忆

### `project/client/styles/global.css`

- `#ip-page` 镜像 `--adm-*`；列表选中/悬停；`.ip-ref-row` / `.ip-fold-*`

### `project/client/src/main.ts`

- 删除内联旧实现，改为 import 调用

## 验收

1. [x] 视觉与制作物品同系
