# 统一战斗预览与播放控制

> 日期：2026-07-28  
> 状态：已实现  
> 与 `design/05-战斗系统.md` §1.0 同步  
> 相关：[三大模块性能优化方案](./2026-07-28-三大模块性能优化方案.md)

## 目标

同一引擎、同一预览、同一播放控制；正式战先抽池再预览，确认后不开二抽。

## 实现摘要

| 模块 | 路径 | 说明 |
|------|------|------|
| 共用预览 | `project/client/src/ui/combatPreview.ts` | `showCombatPreview` |
| 共用播放条 | `project/client/src/ui/playbackControls.ts` | `renderPlaybackControlsHtml` |
| 引擎 | `engine.prepareOfficialBattle` / `runCombatWithSides` / `settleOfficialAutoWin` | 拆分匹配与开战 |
| 正式 UI | `panels.ts` | 抽池→预览→开战；HUD 倍速暂停 |
| 模拟 UI | `sim-battle.ts` | 改用共用预览与播放 HTML |

## 验收

1. [x] 正式战：匹配后再预览真实敌方（或空池提示），确认后不二次抽池  
2. [x] 模拟/正式预览同一 `#combat-preview` 模块  
3. [x] 正式战 HUD 可暂停与倍速  
4. [x] 空池自动胜结算保留  
5. [x] 取消预览不改 phase/金币  

## 明确不做

- 未改对战池 API / 数值公式  
- 正式战战斗卡面未整页 Solid 化
