# 模拟对战 · 交互重构方案

> 状态：已完成
> 日期：2026-07-20
> 设计锚：`design/DESIGN.md`

## 背景

模拟对战功能在上一轮完成了视觉重设计（工作风隐身模式），但交互层存在根本性问题：27 处 `render()` 调用，每次折叠/展开/拖拽都通过 `app.innerHTML = ...` 销毁并重建整个 DOM。这导致滚动位置丢失、CSS 过渡被中断、战斗视图每 100ms 全量重绘。

## 架构决策

将渲染模式从「全量 innerHTML」改为「骨架常驻 + 分区渲染 + 精准 DOM patch」。

核心思路：

```
旧：render() → app.innerHTML = 整页模板 → bindEvents()
     ↑ 27 处调用，每次全毁全建

新：init() → createSkeleton() → 稳定容器 div（只创建一次）
    状态变更 → updateZone(zoneId, newHtml) → 只更新受影响 zone
    事件绑定 → 委托在容器 div 上（不随内容重建）
```

## Zone 更新策略

| 操作 | 更新范围 | 原因 |
|------|----------|------|
| 切换物品池 Tab | `#sb-pool` | 只改变池内容 |
| 切换实体/词条类别 | `#sb-pool` | 同上 |
| 搜索输入（150ms 防抖） | `#sb-pool` | 同上 |
| 物品池折叠/展开 | 无（纯 CSS width transition） | 容器不重建，transition 真正生效 |
| **折叠卡片（6 种）** | **无** | DOM 级操作（CSS class toggle） |
| 拖拽 drop（同侧） | 受影响侧的 BD zone | 树结构变了 |
| 拖拽 drop（跨侧/从池拖入） | 双方 BD zone + 池 zone | 三处都变了 |
| 回合切换 | header + 双方 BD zone | 槽位限制变了 |
| 开始/结束战斗 | 全量切换到战斗/编辑骨架 | 页面模式切换 |
| 战斗 100ms 轮询 | **无 innerHTML** | 纯 textContent patch |
| 战斗暂停/调速/返回 | `#sb-battle-header` | 只按钮状态变 |
| 战斗日志新条目 | 追加 `insertAdjacentHTML` | 不碰已有内容 |

## 关键实现

### 1. 折叠/展开

6 种折叠分两类：

**区块级折叠（词条区块、子实体区块、固定词条、动态词条）**

展开/折叠态内容相同 → 纯 CSS。`renderEntityCard()` 始终渲染完整内容，折叠区块使用 `sb-foldable` class：

```css
.sb-foldable {
  overflow: hidden;
  transition: max-height 200ms var(--sb-ease-out), opacity 150ms;
}
.sb-foldable.sb-folded { max-height: 0; opacity: 0; }
```

点击 toggle → 更新 Set → `el.classList.toggle('sb-folded')` → 结束，不触发任何 Zone 更新。

**卡片级折叠**

展开和折叠 DOM 结构差异大。改为始终渲染展开内容 + 隐藏的折叠信息区，用 CSS 互斥显隐：

```css
.sb-card .sb-card-body-expanded { display: block; }
.sb-card .sb-card-body-collapsed { display: none; }
.sb-card.sb-card-collapsed .sb-card-body-expanded { display: none; }
.sb-card.sb-card-collapsed .sb-card-body-collapsed { display: block; }
```

### 2. 战斗数值精准更新

动态值包裹在带唯一 id 的 `<span>` 中：

```
<span id="cu-hp-p-swordman01">280/280</span>
<span id="cu-sta-p-swordman01">120/120</span>
<span id="cu-cd-p-swordman01-0">1.5s</span>
<span id="cu-ov-p-swordman01">超重</span>
<span id="cu-dead-p-swordman01">阵亡</span>
```

100ms 轮询改为遍历 `[id^="cu-"]` span，只对 textContent 变化的节点做更新——不再替换任何 innerHTML。

### 3. Toast CSS transition

```css
#sb-toast {
  opacity: 0; transform: translateY(8px);
  transition: opacity 200ms var(--sb-ease-out), transform 200ms;
}
#sb-toast.sb-toast-visible { opacity: 1; transform: translateY(0); }
```

`#sb-toast` 是骨架的一部分，永不销毁，transition 始终有效。

### 4. 拖拽事件

保持现有的 `querySelectorAll` + `addEventListener` 模式，不改成事件委托（避免破坏 300 行经过测试的拖拽逻辑）。每次 BD zone 内容更新后重新绑定。

### 5. 滚动位置保持

```typescript
function updateZone(id: string, html: string) {
  const el = document.getElementById(id);
  if (!el) return;
  const st = el.scrollTop;
  el.innerHTML = html;
  requestAnimationFrame(() => { el.scrollTop = st; });
}
```
