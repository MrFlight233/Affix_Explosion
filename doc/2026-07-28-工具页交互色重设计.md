# 工具页交互色重设计

> 日期：2026-07-28  
> 状态：已实现  
> 选定方向：A · 渐进加深（见 `design-previews/2026-07-28-工具页交互色重设计/selection.json`）  
> 与 `design/DESIGN.md` 同步

## 目标

解决「制作物品」「模拟战斗」中鼠标悬停 / 焦点 / 选中态颜色过淡、无法区分当前元素的问题；保留工作风隐身气质，仅加强交互态对比。

约束：

- 范围仅 `#adm-page` / `#sb-page`（不含主游戏 HUD）
- 不改 DOM / TS 逻辑，只改 CSS token 与状态样式
- 选定方向 A：全灰阶加深 + 列表左指示条，不动色相

## 选型

| 方案 | 结论 |
|------|------|
| A 渐进加深 | **已采用** — 风险最低，直接解决辨识度 |
| B 冷蓝强调 | 弃用 — 引入品牌色，超出本次最小目标 |
| C 结构重塑（少填色） | 弃用 — 密集列表左条 alone 可能仍偏弱 |
| D 暗色高密度 | 弃用 — 与主游戏亮色割裂 |

## 根因

| 位置 | 错误行为 |
|------|----------|
| `--adm-accent-subtle` / `--sb-accent-subtle` = `#f5f5f5` | 与 `#fafafa` / `#fff` 几乎同色 |
| `.adm-list-item:hover` = `#f8f8f8`；`.sb-pool-item:hover` = `#f8f8f8` | ΔL 不足，扫一眼认不出 |
| focus ring `rgba(82,82,82,0.1)` | 环对比度过低 |
| selected `#f3f3f3` | 与 hover 难区分 |
| `design/DESIGN.md`「编辑视图完全无色」 | 状态只能靠极淡灰 |

## 实现要点

### Token（adm / sb 对称）

| Token | 新值 | 用途 |
|-------|------|------|
| `--*-accent-subtle` | `#ececec` | Chip/按钮浅底 |
| `--*-hover` | `#e8e8e8` | 列表/行悬停底 |
| `--*-selected` | `#d4d4d4` | 选中底（强于 hover） |
| `--*-focus-ring` | `rgba(38,38,38,0.28)` | focus 环 |
| `--*-indicator` | `#404040` | 列表 3px 左指示条 |
| `--*-drag-over-bg` | `rgba(64,64,64,0.08)` | 拖拽落点底 |

状态层级：`default → hover → focus-visible → selected/active → drag-over`

### `project/client/styles/global.css`

- `#adm-page` / `#sb-page` 根变量追加上表 token
- 列表项 hover/selected 改用 token，并 `box-shadow: inset 3px 0 0 var(--*-indicator)`
- 所有 `rgba(82,82,82,0.1)` focus 环改为 `var(--*-focus-ring)`
- 按钮/Chip hover 使用 `--*-hover` 或加深后的 `--*-accent-subtle`
- drag-over 使用 `--*-drag-over-bg` + accent 边框
- 保留 `@media (hover: none)` 触摸禁用假 hover

### `design/DESIGN.md`

- 改「编辑视图完全无色」为「允许功能性交互态对比；仍无品牌色相」
- 写入交互态 token 与状态层级
- 更新列表项 hover/selected 文档值

## 验收用例

1. [x] 制作物品列表：鼠标扫过能立刻指出当前行（左条 + 更深底）
2. [x] 模拟战斗物品池 / 卡片头 / 空槽：hover 与未悬停明显不同
3. [x] Tab 焦点：`focus-visible` / focus-within 环清晰，且与 hover 不混淆
4. [x] 选中/激活 Chip、列表 selected 比 hover 更强
5. [x] drag-over 落点比普通 hover 更醒目
6. [x] `design/DESIGN.md` 与 CSS token 一致
7. [x] 主游戏 HUD / `:root` 白底黑字未改
