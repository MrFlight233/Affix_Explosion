# slotCost=0 不占槽 + 按消耗占槽

> 日期：2026-07-28  
> 状态：已实现  
> 供其它智能体执行时参考；与 `design/02`、`03`、`04` 同步。

## 目标

统一槽位占用算法：

- **已用** = 下属各项 `slotCost` 之和
- **`slotCost === 0`**：不计入已用、不减少空槽格显示
- 校验、模拟对战卡片标题 `已用/上限`、空槽数量、Admin「已用」提示使用同一算法

适用范围：第一层实体槽、父实体子实体槽、动态词条槽。

## 根因（修复前）

| 位置 | 错误行为 |
|------|----------|
| 词条挂载校验 / 卡片 | 按**条数**占槽，忽略 `slotCost` |
| Admin 实体保存 | `parseInt(...) \|\| 1` 无法存出 `0` |
| Admin 默认子 / 预装动态词条提示 | 按选中**个数**显示已用 |

实体子槽 `countUsedSlots` 此前已按 `sum(slotCost)`，基本正确。

## 实现要点

### 数据层 `project/client/src/game/data.ts`

- `countUsedSlots`：直属实体 `sum(slotCost)`（注释明确 0 不占）
- **新增** `countUsedAffixSlots`：动态词条 `sum(slotCost)`

### 模拟对战 `project/client/src/ui/sim-battle.ts`

- 词条块标题：`usedAffixSlots / dynamicAffixSlots`
- 空槽格数量：`max(0, 上限 - 已用消耗)`
- 拖入 / BD 内移动词条：`used + adef.slotCost > 上限` 则拒绝
- 悬浮提示与行内展示槽耗

### Admin `project/client/src/ui/admin.ts`

- 实体 / 词条 `slotCost` 输入 `min="0"`；保存允许 `>= 0`
- 默认子实体「已用」= `sum(所选实体.slotCost)`
- 预装动态词条「已用」= `sum(所选词条.slotCost)`

## 验收用例

1. 实体 `slotCost=0` 可保存；放入父槽 / 第一层不增加已用、不减空槽
2. 词条 `slotCost=0` 可挂多个（在条数/其它限制允许时）且不占动态槽
3. `slotCost=2` 的词条在剩余 1 槽时拖入失败
4. 卡片标题与空槽格与校验一致
5. Admin 选中高消耗默认子 / 预装词条时「已用」正确累加
