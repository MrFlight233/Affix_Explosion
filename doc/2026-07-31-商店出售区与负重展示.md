# 商店出售区、回顾价值、卡片负重比

> 计划文档：供其它智能体执行/对照验收。

## 1. 商店出售区过小

- **根因**：`#merchant-panel` 有 `data-fg-zone="sell"`，但高度未撑满 `#event-area`，空白落在区外。
- **改法**：`.fg-layout #event-area` 列 flex；商人面板 `height:100%` 列 flex；`#fg-shop-item-list` `flex:1; overflow-y:auto`。

## 2. 历史回顾悬停价值

- **根因**：`bindSbTooltips(detail)` 未传 `getInstance`，悬停用模板交付价。
- **改法**：从双方 BD 建 `instanceId → ItemInstance`，传入 `bindSbTooltips`；换场次更新。

## 3. 卡片负重比

- **展示**：启动端 `负重: {现有}/{有效上限}`（如 `9g/30g`）。
- **API**：`computeStarterLoad(item)` 对齐引擎重量与 loadBonus 公式。
- **覆盖**：entityCard（模拟/正式/回顾）+ simTooltip。

- [ ] 历史回顾悬停价值与卡片总价值一致
- [ ] 启动端卡片显示现有/上限负重
