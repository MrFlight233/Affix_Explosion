# 启动端主动动作触发方案

## 背景

当前战斗引擎中，启动端（starter）实体如果拥有主动动作（`isActive=true`），在战斗时完全不会触发。引擎只在 `collectFromChildren()` 中遍历启动端的**子装备**来收集武器，启动端自身被当作纯粹的"躯体"载体。

## 改动概览

| 文件 | 改动 |
|------|------|
| `project/client/src/game/engine.ts` | `calculateCombatSnapshots()` — 启动端自身主动动作收集 |
| `project/shared/types.ts` | 更新 `damage` 字段注释 |
| `project/client/src/ui/sim-battle.ts` | `renderCardKeyInfo()` + `renderEntityCard()` — 启动端主动动作卡片显示 |
| `project/client/src/ui/panels.ts` | `updateCombatDynamicValues()` — 实时倒计时插值 |
| `design/05-战斗系统.md` | 补充启动端自身动作说明 |

## 改动详情

### 1. 引擎 (`engine.ts`)

在 `calculateCombatSnapshots()` 中，starter 收集完子装备武器后，检查自身 `isActive`。若为 true，创建武器并 unshift 到 `collected.weapons` 最前面（index 0）。该武器随后被伤害归一化循环处理，受益于 passiveDamageBonus。

### 2. 模拟战斗卡片 (`sim-battle.ts`)

- `renderCardKeyInfo()`: starter 的 key info 行在 HP/耐力后追加主动动作信息（伤/耗时/顺序）
- `renderEntityCard()`: 启动端有 isActive 时也渲染"主动动作" block

### 3. 战斗面板倒计时 (`panels.ts`)

`updateCombatDynamicValues()` 加入 wall-clock 插值：
- `displayMs = Math.max(remainingTime - (Date.now() - lastTickWallTime), 0)`
- 检测 `remainingTime` 变化来识别引擎 tick
- 保持 100ms setInterval 不变

### 4. 设计文档

- `shared/types.ts`: damage 注释"启动端始终为 0" → "启动端: 自身主动动作伤害"
- `design/05-战斗系统.md`: 补充启动端自身动作说明
