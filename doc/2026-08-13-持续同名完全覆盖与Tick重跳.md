# 持续同名完全覆盖与 Tick 重跳

> 日期：2026-08-13  
> 状态：已实现  
> 拷问：已结束  
> 部分取代：[`doc/2026-08-04-命中效果即时与持续.md`](./2026-08-04-命中效果即时与持续.md) 中「同 buffKey 满时长+max / Tick 刷新不重跳」等条款  
> 与 `CONTEXT.md`、`design/02-名词解释.md`、`design/05-战斗系统.md`、`docs/adr/0001-on-hit-instant-vs-duration.md` 同步

## 目标

- 持续效果同一性改为**名称**（同名互抢、异名并行）。
- 同名后写**全量覆盖**（不再数值 max）。
- Tick：首次施加与同名覆盖均**立即跳**并**重置间隔**。
- Admin：持续名称必填、本模板内重名禁存、隐藏 buffKey、文案点明同名互抢。
- 日志：首挂「施加」、再挂「覆盖」。

## 终局规则（摘要）

| 项 | 规则 |
|----|------|
| 轨道 | 名称（持续必填） |
| 覆盖 | 后写整段替换；底盘与 Tick 同一套 |
| Tick | 施加/覆盖均立即跳 + 重置间隔 |
| buffKey | 结算忽略；可跟名存储；不删字段 |
| 上限降 | current 钳到新上限 |
| 被动 | 不占持续轨；同属性相加 |
| 日志 | 施加 / 覆盖；不写旧→新 |
| 内容 | 不立抢槽支柱；不扫种子 |

## 修改点 1：同名全量覆盖

### 现状

同 `buffKey` 刷新：`remainingMs` 换新时长，`value = max(旧,新)`；半合成、顺序敏感。

### 期望

同名称：后写覆盖全部字段（时长、数值、stat、op、间隔、weaponIndices 等）。

### 原因

心智简单；与「名称即轨道」一致；避免弱续时/强抬伤只在一种顺序成立。

### 实现

- 文件：`project/client/src/game/battle/durations.ts` — `attachOrRefreshDuration`
- 去掉 `Math.max`；同名分支全量赋值；Tick 时 `msUntilNextTick = tickIntervalMs`
- 匹配键使用名称（见修改点 3）

---

## 修改点 2：Tick 施加与覆盖均立即跳

### 现状

`onhit.ts` 仅 `if (tick && isNew)` 立即跳；刷新不重跳、不重置间隔。

### 期望

Tick 在 attach 成功后无论首挂或同名覆盖都立即打出一跳；间隔已重置。

### 原因

完全覆盖 = 新实例就位；接受命中触发型毒手感（拷问 #1、#15）。

### 实现

- 文件：`project/client/src/game/battle/onhit.ts`
- 条件改为 `if (tick)`（在 `attachOrRefreshDuration` 之后）
- 单测：覆盖后 HP 再扣一跳

---

## 修改点 3：同一性 = 名称；忽略配置 buffKey

### 现状

可配置与名称不同的 `buffKey`；空则回退名称。

### 期望

结算匹配键强制为解析后名称；配置 `buffKey` 不参与互抢。

### 原因

纯同名=同轨（拷问 #5b、#8）；避免第二套黑箱键。

### 实现

- `project/shared/hitEffectUtil.ts` / 开战 stamp / `onhit` attach 前：轨道键 = `resolveHitDisplayName`
- 运行时 `ActiveDuration.buffKey` 可存该名称（少改结构）
- 单测：异 buffKey 同名称仍互抢；异名不互抢

## 修改点 4：Admin 制作校验与文案

### 现状

可持续空名；展示 buffKey；提示仍写「不同 buffKey」。

### 期望

- 持续名称必填（空则不可保存）
- 同一实体/词条模板内多条持续同名 → 禁止保存
- 隐藏 buffKey；标签「名称（同名互抢）」+ 短提示
- 宿主+词条跨模板同名：不检测（靠起名）

### 原因

制作侧防自盖；跨物品同名留给 BD（拷问 #9–13）。

### 实现

- `project/client/src/ui/adminHitEffects.ts`（及实体/词条保存调用链）
- 校验：`kind===duration` 时 displayName trim 非空；同列表持续名唯一

---

## 修改点 5：战斗日志用词

### 现状

`挂上` / `刷新`。

### 期望

`施加` / `覆盖`；不写旧→新；Tick 立即跳仍单独即时行。

### 原因

语体与全覆盖对齐（拷问 #25–28）。

### 实现

- `formatDurationLogLine` in `onhit.ts`：`isNew ? '施加' : '覆盖'`
- 单测断言新动词；更新凡断言「挂上」「刷新」之处

### 现状

### 期望
