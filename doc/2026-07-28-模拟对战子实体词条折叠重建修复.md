# Bug 修复：子实体词条折叠破坏卡片树

> 日期：2026-07-28  
> 状态：已实现

## 问题描述

1. 点击子实体的固定/动态词条折叠后，第一层实体消失，只剩该子实体。  
2. 点击第一层固定/动态词条折叠后，子实体无法再折叠/展开。

## 根因分析

### Bug 1：父卡被替换

**位置**：`project/client/src/ui/sim-battle.ts` → `rebuildSingleCard`

`.sb-card:has([data-cardtoggle=子实体id])` 先命中包含该子实体的祖先第一层卡片，再用子实体数据 `replaceWith`，整棵树被替换。

**修复**：只用 `[data-cardtoggle=id]` + `closest('.sb-card')`。

### Bug 2：嵌套折叠失效

**位置**：`bindCardCollapseEventsOnCard`

`querySelector('[data-cardtoggle]')` 只绑最外层；父卡 rebuild 后嵌套子卡 header 无监听。

**修复**：`querySelectorAll('[data-cardtoggle]')` 逐个绑定，折叠作用于各自 `closest('.sb-card')`。

### 同类：build tooltip

rebuild 后仅 battle 重绑 tooltip；build 同步调用同一套 per-card 绑定。

## 修复方案

### `project/client/src/ui/sim-battle.ts`

- `rebuildSingleCard` 修正卡片定位  
- `bindCardCollapseEventsOnCard` 全量嵌套 cardtoggle  
- rebuild 后统一 `bindTooltipEventsOnCard`
