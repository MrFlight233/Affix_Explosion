# 效果展示名为空时回退宿主名

## 背景

Admin 新增效果时，展示名（`displayName`）原为默认中文名（如"伤害""生命加成"），保存时强制填充。
现在改为默认为空，展示时自动回退为所属实体名或词条名。

## 定稿

### 存储

- `displayName` 允许空串（`''`），Admin 新效果默认为空。
- 持续效果 `buffKey`：保存时空串入库，不固化 resolve 值（避免改名后旧 key 残留）。

### 展示回退链

`displayName → ownerName → 「未命名效果」`

- **配置面**（卡面、悬浮、物品池、Admin 预览）：统一取当前查看上下文名（看实体 → 实体名，看词条 → 词条名）。
- **战斗日志**：stamp 阶段区分来源粒度——词条贡献取词条名，实体自身取实体名。

### 持续 buffKey

与展示名同一套回退：`buffKey → 已填 displayName → ownerName → 「未命名效果」`。

同宿主多条持续且展示名/buffKey 皆空 → 接受抢同一 buff 槽（同键刷新合并）。
Admin 持续效果区有弱提示：「空展示名/空 buffKey 会共用宿主名；多条持续请填不同展示名或 buffKey」。

### 战斗 stamp

- `collectHostOnHitBag`：实体自身效果用实体模板名 stamp；词条贡献效果用词条模板名 stamp。不写回模板库。
- `collectPassiveSourcesFromTree`：同上，实体分支取实体模板名，词条分支取词条模板名。
- stamp 函数：`stampOnHitEffectList(list, ownerName)` / `stampPassiveEffectList(list, ownerName)`。

### 明确不改

- 存量种子已有的 displayName / buffKey 不动。
- `seed.ts` 程序默认效果（`displayName: '伤害'` / `displayName: '回复'`）保留。
- `engine.ts` 运行时生成的硬编码效果保留。
- 效果结算数值、applyTo、持续刷新语义不变。

## 核心文件

| 文件 | 变更 |
|------|------|
| `shared/effectIdentityUtil.ts` | 新建：`resolveEffectIdentityRaw` + `FALLBACK_DISPLAY_NAME` |
| `shared/hitEffectUtil.ts` | normalize 允许空名；新增 resolve/stamp 函数；`formatHitEffectLine` 加 `ownerName` 参数 |
| `shared/passiveBonusUtil.ts` | normalize 允许空名；新增 resolve/stamp 函数；`formatPassiveEffectLine` 加 `ownerName` 参数 |
| `client/engine.ts` | `collectHostOnHitBag` / `collectPassiveSourcesFromTree` 调用 stamp |
| `client/activeActionDisplay.ts` | format 函数加可选 `ownerName` 参数 |
| `client/passiveBonusDisplay.ts` | format 函数加可选 `ownerName` 参数 |
| `client/adminHitEffects.ts` | 默认空名；buffKey 保存为空；弱提示 |
| `client/adminPassiveBonuses.ts` | 默认空名；不再用 `PASSIVE_STAT_LABEL` 填充 |
