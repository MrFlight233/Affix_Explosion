# 战斗 0.0s 预处理入日志 + 敌我颜色

> 日期：2026-08-17  
> 状态：已实现  
> 决议：日志粒度 **1B 明细**；敌我标识 **2B 颜色为主**（角色名着色，不加 `[我方]/[敌方]` 文字前缀）  
> 同步：`design/05-战斗系统.md`

## 修改点 1：预初始化改为 0.0s 执行相位并出明细日志

### 现状

- `recomputePassiveBonuses(..., includeDead=true)` 在 Simulator 构造与引擎开战前静默执行，不 emit。
- 首条演算事件在首次 `step()` 后为 0.1s。
- 引擎另注入空洞「战斗开始」哨兵。

### 期望

- 开战有明确 0.0s 执行相位（含 0 血被动 + 上限同步；不开火/不回复）。
- 明细日志：来源 → 目标 → 每条被动效果；仍为 0 血则 0.0s 击杀。
- Simulator bootstrap 统一产出；去掉引擎空洞「战斗开始」双条。

### 原因

把构造副作用收成时间线首段，便于对照被动拉血/抬上限。

### 实现

- `project/client/src/game/battle/passives.ts`：可观测记录。
- `project/client/src/game/battle/simulator.ts`：`bootstrapAtZero()`；构造不再静默预初始化。
- `playback.ts` / `battle.worker.ts`：step 前 bootstrap。
- `engine.ts`：去掉空洞「战斗开始」注入。

## 修改点 2：战斗日志敌我颜色

### 现状

- `CombatEvent` 无 side；日志只拼名字。

### 期望

- `actorSide` / `targetSide`；名字用 CSS 着色；旧档无 side 退化。

### 原因

同名实体难辨阵营。

### 实现

- `types.ts` / shared：字段增补。
- Simulator 所有 emit 写侧别。
- `activeActionDisplay.ts` + `BattleLogPanel.tsx` + `global.css`。

## 验收

- [ ] 0.0s 预处理明细后才有 ≥0.1s 攻击类事件
- [ ] 拉不起的 0 血单位 0.0s 击杀
- [ ] 正式局/模拟战/回顾颜色一致；旧日志不崩
- [ ] design/05 §1.1 已更新
- [ ] 单测：bootstrap `time===0`；胜负与改前一致

## 明确不做

- 不开火/耐力回复挪到 0.0s
- 不加 `[我方]`/`[敌方]` 文字前缀
- 不改 combatPhase / combatSeed 协议
