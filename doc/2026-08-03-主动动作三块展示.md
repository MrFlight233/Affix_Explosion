# 主动动作三块展示 + 效果文案 + 战斗日志

日期：2026-08-03

## 目标

主动动作在制作物品 / 模拟战 / 正式局的卡片与悬浮窗统一展示消耗、目标、效果；效果行与战斗日志同源字段；日志抬头为「对…使用…」，子行带单位名与前后值。

## UI 定案（方向 A · 扁平工牌 · 左对齐）

- **信息顺序**：消耗（耐力/间隔）→ 目标（索敌）→ 效果（§2.1 多行）
- **层级**：仅「主动动作」一级块标题；**不使用**副标题分节
- **对齐**：主动动作区内标签与描述一律**左对齐**；悬浮主动区不用 `tipkv` 的左右拉开
- **效果行**：不加「效果:」前缀；一行一条
- Admin / 物品池：短标签（`耐力消耗` 等），无「消耗 ·」双前缀与元提示

卡片形态示例：

```
主动动作
耐力: 15  间隔: 1.0s
索敌: 敌人 · 随机 · 1
伤害 被命中 血量 - 10
吸血 启动端 血量 + 2
```

## 信息架构

| 块 | 内容 |
|----|------|
| 消耗 | 耐力消耗；间隔/耗时（战斗可显示倒计时） |
| 目标 | 索敌摘要 |
| 效果 | `onHitEffects` 一条一行 |

词条仅有「效果」块。

## 配置面效果行（卡 / 悬浮 / Admin / 物品池）

```
{displayName} {roleLabel} {statLabel} {opSymbol} {magnitude}
```

- roleLabel：`被命中` / `启动端` / `被触发`；多选 applyTo **合并一行**，角色用 `/` 连接（如 `被命中/被触发/启动端`）；战斗日志仍按实际单位各结算一行
- magnitude：仅固定 `10`；仅百分 `20%`；两者 `5 + 10%`（空格 ` + `）
- 折叠摘要：`耐耗N · {目标摘要} · {首条展示名}`；多效果 `伤害等3条`

## 战斗日志

抬头：`[时间s] {actor} 对 {target} 使用 {weapon}`

子行：`{displayName} {affectedName} {statLabel} {opSymbol} {value}  ({HP|耐力}: {before} -> {after})`

击杀：`[时间s] {name} 击杀!`（不变）

## 实现文件

- `project/client/src/game/activeActionDisplay.ts` — 共用文案
- `project/shared/hitEffectUtil.ts` — magnitude / 角色标签复用
- `onhit.ts` / `simulator.ts` / `types.ts` — before/after、单位名

## 非目标

不改结算语义与选目标；卡面不塞开火后 before/after；不实现四向预览中的 B/C/D。
