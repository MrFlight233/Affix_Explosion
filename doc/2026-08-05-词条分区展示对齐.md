# 词条分区与展示对齐

> 日期：2026-08-05  
> 状态：已实现  
> 依据：计划「词条分区展示对齐」

## 定稿

词条不做完整主动动作（无主动消耗）。战斗相关分区：

```
基本信息 / 前置条件
主动目标覆写 — 覆写模式（不修改/修改）+ targetingModifier 字段
主动效果 — onHitEffects
被动加成 — 被动目标 + 被动效果
```

「效果描述」(`effect` 文案) 留在基本信息，不与主动效果混淆。

## 改动落点

- `admin.ts` `buildAffixForm` 改名与重排
- `itemPool.ts` / `entityCard.ts` / `simTooltip.ts` / `tooltip.ts`
- `design/04-词条介绍.md`、`07-模拟对战设计系统.md`、本文件

## 手测

1. Admin：主动目标覆写 → 主动效果 → 被动加成；覆写显隐与保存正常
2. 物品池 / 卡面 / 悬浮标题一致；效果描述仍为文案字段
3. 仅被动 / 仅 onHit / 仅覆写的词条只显示对应块
