# 模拟对战：排序占位残留导致无法放入新槽

> 日期：2026-07-28  
> 状态：已修复  
> 文件：`project/client/src/ui/sim-battle.ts`

## 现象

拖拽实体/词条时，若先划过已有卡片触发排序占位条，再移到空槽位放下：

1. 排序占位条不消失  
2. 无法正常放入新槽（实际被旧的 `lastHover` 劫持成排序）

## 根因

1. **空槽 / 子区 / 词条区 drop** 只要存在 `lastHover` 就强制走 `handleDropOnCard`，即使指针已离开排序目标。  
2. **物品池 `dragend`** 未调用 `clearPlaceholder()`，取消或异常结束时占位残留。  
3. **`bindDropZone` 的 drop** 结束后未统一清理占位。

## 修复

- 空槽：`dragover` / `drop` 清除占位，只走 `handleDropInDeploy`。  
- BD / 子区 / 词条区：仅当 drop 目标仍在悬停卡片或占位条上时才排序（`trySortDrop`）。  
- 物品池 `dragend` 与 `bindDropZone` drop 末尾统一 `clearPlaceholder()`。

## 验收

1. 划过卡片出现占位 → 移到空槽 → 占位消失，可放入。  
2. 划过卡片后直接在占位/卡片上松开 → 仍正常排序。  
3. 从物品池拖起后取消（Esc/拖出）→ 无残留占位。
