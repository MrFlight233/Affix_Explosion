# Admin 命中效果：先选数据再定类型

> 日期：2026-08-04  
> 状态：已实现  
> 相关：`doc/2026-08-04-Admin命中效果保存丢失.md`

## 目标

效果编辑改为：**先选影响数据 → 再暴露合法的即时/持续与 Tick**，避免「先选类型再过滤数据」导致选项突然变少、不好理解。

## 规则（与引擎白名单一致）

| 所选数据 | 类型可选 | Tick 展示 | 形态 |
|----------|----------|-----------|------|
| HP / 耐力 / 倒计时 | 即时、持续 | 仅「持续」时显示（必填间隔） | 即时；或 Tick 壳 |
| 上限 / 回复 / 触发耗时 / 耐力消耗 / 重压 | 仅持续（锁定） | **不展示**（恒为空） | 底盘持续 |

## 实现要点

- `project/client/src/ui/adminHitEffects.ts`
  - 「数据」下拉始终列出全部属性
  - 选数据后：`syncKindTickUi` 重建类型选项、显隐 Tick/持续时长区
  - 底盘属性：类型强制持续，Tick 输入清空且隐藏
  - 即时属性 + 持续：显示 Tick，保存校验要求 `tickIntervalMs > 0`
  - 字段顺序：预览 → 展示名称 → buffKey（仅持续显示）→ 影响数据 → 类型 → …
  - 保留 `collectOnHitEffectsFromDom` 保存前 normalize

## 验收

- [ ] 选「生命恢复」→ 类型只有持续、无 Tick、有持续时长
- [ ] 选「HP」→ 可选即时/持续；切持续后出现 Tick
- [ ] 即时 HP 伤害可保存；持续生命恢复（空 Tick + 时长）可保存
- [ ] 持续 HP 未填 Tick → 保存被拦并提示
