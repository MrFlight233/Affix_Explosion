# 双方 BD 界面身份键

> 日期：2026-08-14  
> 状态：已实现  
> 与 `design/08-正式局设计系统.md` 同步

## 目标

页面同时展示双方 BD 时，折叠、重建、悬浮窗查找各自独立。覆盖：模拟对战、正式对战、结算/历史回顾。

## 选型

| 方案 | 结论 |
|------|------|
| 敌方整树 remap instanceId | 弃用：易漏路径、污染展示副本 |
| **UI 侧向作用域键 `side:instanceId`** | **已采用** |

不改 BD / 对战池 / 存档中的真实 `instanceId`；`cu-*-p/e-*` 数值 id 保持现状。

---

## 修改点 1：Collapse 公共键 API

### 现状

`collapseItemTree` / Collapse Set 只用裸 `instanceId`，敌我同 id 时折叠状态串扰。

### 期望

统一用 `collapseKey(side, instanceId)` 写入/读取折叠集合。

### 原因

UI 身份与数据 id 解耦，存档与对战池不变。

### 实现

**文件**：`project/client/src/ui/build/types.ts`

- 新增 `collapseKey` / `parseCollapseKey` / `instanceIdFromCollapseKey`
- `collapseItemTree(item, collapse, side)`
- `collapseAllOfficialBuild`：BD→`player`，仓库→`warehouse`

---

## 修改点 2：卡片渲染写作用域键

### 现状

`data-cardtoggle` 等与 `collapsed*.has` 均为裸 id。

### 期望

折叠相关 data-* 与 has 判断均用 `collapseKey(side, instanceId)`；拖拽 `data-instance` 仍为裸 id。

### 原因

绑定层直接读 dataset 即可，无需再拼 side。

### 实现

**文件**：`project/client/src/ui/build/entityCard.ts`

- 所有折叠 Set 读写与 toggle 属性改用作用域键
- header 可带裸 `data-instance` 供 tooltip

---

## 修改点 3：只读战斗卡绑定 + 侧向查找

### 现状

`bindReadonlyBattleCardUi` 用裸 id；`getOfficialCombatInstance` / tooltip lookup 先查己方再敌方，撞 id 时错绑。

### 期望

折叠用 dataset 完整键；lookup 按 `.sb-card[data-side]` 只查对应侧。

### 原因

折叠与悬浮窗都必须侧向隔离。

### 实现

**文件**：

- `project/client/src/ui/officialCombat.ts`
- `project/client/src/ui/build/simTooltip.ts`（lookup 签名支持可选 `side`）
- `project/client/src/ui/build/battlePatch.ts`（dead class：从 cardtoggle 解析裸 id）

---

## 修改点 4：模拟战 / 探险 / 结算回顾对齐

### 现状

`sim-battle` 的 `querySelector([data-cardtoggle=id])`、`collapseAllCards`、探险 `collapseItemTree`、`runReview` 默认折叠与 lookup 均未侧向隔离。

### 期望

上述路径一律使用作用域键；重建/查找限侧或带 side。

### 原因

三处双 BD 场景共用同一套卡片 API。

### 实现

**文件**：

- `project/client/src/ui/sim-battle.ts`
- `project/client/src/ui/officialExplore.ts`
- `project/client/src/ui/runReview.ts`
- `project/client/src/ui/panels.ts`（开战默认折叠敌方树带 `enemy`）
