# 命中效果：即时 / 持续 扩展（执行规格）

> 状态：**部分规则已被取代**。同键 max / Tick 刷新不重跳等条款见新方案 [`doc/2026-08-13-持续同名完全覆盖与Tick重跳.md`](./2026-08-13-持续同名完全覆盖与Tick重跳.md)。本文其余（白名单、量公式、重压等）仍可参考。  
> 术语见仓库根目录 [CONTEXT.md](../CONTEXT.md)；决策见 [docs/adr/0001](../docs/adr/0001-on-hit-instant-vs-duration.md)、[0002](../docs/adr/0002-burden-vs-equipment-load.md)。

## 1. 目标

在现有 `onHitEffects` 管道上支持更多数据（上限、双回复、重压、武器耗时/倒计时/耐耗），并引入持续效果，同时守住：

- 底盘必有寿命；当前池 / 本轮 CD 仅即时
- 装备负重 ≠ 重压
- percent 相对上限（非伤害量）

## 2. 效果结构（配置）

在现有字段上扩展：

| 字段 | 说明 |
|------|------|
| `kind` | `'instant' \| 'duration'` |
| `durationMs` | `duration` 必填，>0 |
| `tickIntervalMs` | 可选；有则本条为 **Tick 壳**，无则为 **底盘修饰**（互斥） |
| `buffKey` | `duration` 必填字段；可为空串，战斗进门前通过回退链（displayName → 宿主名 → 「未命名效果」）resolve |
| `displayName` / `stat` / `op` / `params` / `applyTo` | 同现管道；名称可为空串，展示时回退为宿主名 |

约束：

- 持续：`op` 仅 `gain` \| `loss`（禁止 `set`）
- 即时：可 `gain` \| `loss` \| `set`；stat ∈ 当前 HP、当前耐力、`remainingTime`
- 持续底盘：stat ∈ maxHp、maxStamina、maxLoad、hpRegen、staminaRegen、actionTime、staminaCost、burden（重压）
- Tick 壳：stat ∈ 即时白名单；每个 tick 打出一条即时

## 3. 量公式

```text
value = floor(cap × percent / 100) + amount
```

| stat | cap |
|------|-----|
| hp / stamina | totalHp / maxStamina |
| maxHp / maxStamina / maxLoad | 变更前该上限 |
| burden | 目标 maxLoad |
| hpRegen / staminaRegen | totalHp / maxStamina |
| actionTime / staminaCost | 开战武器快照 |
| remainingTime | 开战快照 actionTime |

- 持续：挂上/刷新时算死为固定量；同键刷新用当时 cap 重算再与旧值 max
- **不做**伤害量%吸血；吸血 = 两条即时（对目标 loss + 对启动端/被触发 gain）

## 4. 持续运行时

- 同 `buffKey`：满时长 + 数值 max；Tick：**不重跳、不重置间隔进度**
- 不同键：并行；同属性修饰 **代数相加**
- Tick：挂上 **立即首跳**，再每 `tickIntervalMs` 跳；**周期跳独立写入战斗日志**（不挂在武器攻击事件下）。同键刷新仍不重跳。
- 死亡（HP≤0）：清空该单位全部持续
- 到期：卸底盘修饰 / 停止 tick

## 5. 重压与超重

- 运行时字段：`burden`（重压）；保留装备 `currentLoad` / `maxLoad`
- `isOverloaded = currentLoad + burden > maxLoad` → 现有 1.5× 耐耗
- 命中不改装备树重量、不重算装备负重

## 6. 武器与 CD

- `applyTo` 选单位；武器类：持有开火武器则只改该武器，否则改该单位全部主动武器
- 开火后 `remainingTime = actionTime`，再应用对本开火武器的即时 `remainingTime`（延迟，防覆盖）
