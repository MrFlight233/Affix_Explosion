# 开局空 BD、读档保真、折叠、词条卡、战斗布局

供其它智能体执行的实现清单（与计划一致）。

## 规则

- 新游戏：`deploySlots` / `warehouse` 皆空，不自动部署默认 starter。
- 读档保真：空 BD 读回仍为空；`sanitizeMissingEntityDefs` 不得在空 BD 时补人类。
- 空 BD 允许开战。
- 拖入 BD/仓库成功后：该物品子树 `collapsedCards` 默认折叠。
- 继续游戏进探险壳：BD+仓库全树默认折叠。
- 独立词条卡展开态对齐悬停窗信息密度。
- 战斗壳：上左右友/敌 BD，下日志。

## 验收

- 新游戏 BD/仓库空；空档继续无人类；继续折叠；拖入折叠；词条卡有内容；战斗下日志。

- 战斗布局必须用 `#main-layout.fg-combat { display:grid }`，否则会被 `#main-layout { display:flex }` 的 ID 优先级盖过，仍呈三列。
- 进入战斗壳时 `applyCombatDefaultCollapse`：友方 + 敌方可折叠卡全部默认折叠。
- 空 BD 允许开战（已去掉「请先配置出场 BD」拦截）。
- 战斗壳上下横分界线 `#combat-h-split` 可拖，日志高度 `--fg-combat-log-pct`，存 `fg-combat-split`。
