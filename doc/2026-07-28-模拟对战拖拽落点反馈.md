# Bug 修复：模拟战斗拖拽落点与排序线不可见

> 日期：2026-07-28  
> 状态：已实现  
> 与 `design/07-模拟对战设计系统.md` 同步

## 问题描述

1. 拖拽实体/词条到空槽或 BD 区域时，落点颜色几乎无法区分。  
2. 同层拖拽排序时看不到插入位置指示线。

## 根因分析

### Bug 1：排序指示线不可见

**位置**：[`project/client/src/ui/pointerDrag.ts`](../project/client/src/ui/pointerDrag.ts) + [`project/client/styles/global.css`](../project/client/styles/global.css)

`.sb-drag-gap` / `.sb-drag-ghost` 挂在 `document.body`，而 `--sb-accent` 等 token 定义在 `#sb-page`。`background: var(--sb-accent)` 在 body 子节点无效 → 指示线无色。`updateGap()` 逻辑本身正常。

**修复方向**：ghost/gap 挂到 `#sb-page`；CSS 为 gap/ghost 提供硬编码 fallback。

### Bug 2：空槽落点无高亮

**位置**：[`pointerDrag.ts`](../project/client/src/ui/pointerDrag.ts)

CSS 已有 `.sb-empty-slot.drag-over`、`#sb-pool.remove-target`，但 Pointer 引擎从不挂这些类。空槽 mount 时 `insertIndex` 为 `undefined`，gap 也关闭 → 零反馈。`--sb-drag-over-bg` 也偏淡。

**修复方向**：新增 `updateDropHighlight`；加深 drag-over 样式。

## 修复方案

### 修改 1：Pointer 引擎

**文件**：`project/client/src/ui/pointerDrag.ts`

- ghost/gap append 到 `#sb-page`（无则 `body`）
- `updateDropHighlight(hit)`：空槽 `drag-over`、列表 `drag-over`、池 `remove-target`；teardown 清空
- `pointermove` 同步调用 `updateGap` + `updateDropHighlight`

### 修改 2：样式

**文件**：`project/client/styles/global.css`

- 加深 `--sb-drag-over-bg`，加 `--sb-drag-over-border`
- 加强 `.sb-empty-slot.drag-over`、`[data-sort-list].drag-over`
- `.sb-drag-gap` 加高 + 实色 fallback；`.sb-drag-ghost` 同样 fallback

### 修改 3：设计文档

**文件**：`design/07-模拟对战设计系统.md` — 拖拽反馈约定
