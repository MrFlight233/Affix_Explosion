# 模拟对战 Pointer 拖拽重构

> 日期：2026-07-28  
> 状态：已实现  
> 取代：HTML5 DnD + DOM 占位条排序

## 选型

| 方案 | 结论 |
|------|------|
| HTML5 + 占位条 | 已踩坑（总排末尾、卡顿），弃用 |
| SortableJS | 零依赖项目 + 复杂 slotCost 校验，不引入 |
| **Pointer 自研** | 已采用 |

## 实现要点

- 新模块：[`project/client/src/ui/pointerDrag.ts`](../project/client/src/ui/pointerDrag.ts)
- 模拟对战：[`sim-battle.ts`](../project/client/src/ui/sim-battle.ts) 委托 `pointerdown`，松手 `commitPointerDrag` 一次改数据
- DOM 约定：`data-sort-list` / `data-sort-item` / `data-drag-handle` / `.sb-empty-slot` / `#sb-pool`
- 视觉：`sb-drag-ghost` + `sb-drag-gap`（fixed + transform，无 height 动画）
- 删除文件顶 `document.body` 调试 drop；旧 `.sb-drop-placeholder` 不再使用

## 验收

1. 第一层拖到目标上/下 → 插入对应位置，不沉底  
2. 木桩 / starter 均可同层重排  
3. 子实体、词条同列表排序正确  
4. 空槽挂载、拖回池移除、slotCost 超额拒绝  
5. 拖拽跟手；无 `BODYdrop` toast  
6. 折叠单击仍可用（移动阈值内不激活拖拽）
