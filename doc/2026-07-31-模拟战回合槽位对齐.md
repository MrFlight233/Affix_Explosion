# 模拟战回合选择与槽位对齐正式局

日期：2026-07-31  
方案选定：仅战斗回合 + 公式槽位（用户确认方案 2）。

## 问题

模拟战仍用奇数探险回合，且槽位上限 = `round`，与正式设定不一致：

- 正式：回合 1–10；槽位 `floor((round+1)/2)`
- 正式对战池：`enterBattleRound` 后按 **偶数战斗回合** 上传/抽取

## 落地

文件：[`project/client/src/ui/sim-battle.ts`](../project/client/src/ui/sim-battle.ts)

- `COMBAT_ROUNDS = [2,4,6,8,10]`，默认 `round: 2`
- 选项文案：`回合N (战斗, 槽位X)`，`X = getFirstLayerSlots(N)`
- `canPlaceInSlot` / BD 头展示均用 `getFirstLayerSlots`
- 抽池 / 上传仍用 `state.round`（现为战斗回合，可对齐正式池）

文档：[`doc/模拟对战功能方案.md`](./模拟对战功能方案.md) 已同步。
