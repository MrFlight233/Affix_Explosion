# Toast 提示统一优化

日期：2026-07-31  
供其它智能体执行 / 回归对照。

## 问题

模拟战 `#sb-toast` 仅有淡入动画、无 `position: fixed`，作为页面文档流末尾块，提示出现在左下角。

## 方案（已落地）

1. **样式**：`#toast` / `#sb-toast` / `.app-toast` 共用顶中 fixed（`top: 36px; left: 50%`），长文案 `max-width` 居中。
2. **逻辑**：[`project/client/src/ui/toast.ts`](../project/client/src/ui/toast.ts) 的 `showAppToast`；`panels` / `sim-battle` / `pointerDrag` / `dragDrop` 接入；禁止再对 `#sb-toast` 设 `display:none`。
3. **时长**：默认 2200ms；文案 ≥18 字或含「需要前置」「不可移除」→ 3000ms。
4. **文案**：`已出售 · +N 金` → `已出售 · +N 金币`。Admin `#adm-toast` 不改。

## 验收

- 模拟战挂载/卸下失败：顶部居中提示，非左下角。
- 连续 toast timer 会重置，不叠乱。
- Admin 仍底部居中。
