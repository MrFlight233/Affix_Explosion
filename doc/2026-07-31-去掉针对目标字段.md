# 去掉针对目标：阵营仅走过滤

## 规则

- 阵营只通过 `filterBy` 中的 `友方`/`敌人`/`自己` 配置（OR）。
- **无任何阵营标签 → 候选池为空**：动作仍触发、扣耐力、重置 CD，不结算目标。
- 删除 Admin/展示/词条覆写中的「针对目标」；DB `target_faction` 列保留，写入清为 null。
- **旧档迁移（运行时）**：`filterBy` 无阵营标签时，把遗留 `targetFaction` 并入过滤（`所有`→友方+敌人）；迁移后仍无阵营则空池。
- Admin 新建主动默认勾选「敌人」；允许不勾（空放）。

## 改动点

- `targetingUtil.resolveFactionTags`：无回退默认敌人
- `engine._resolveWeaponTargeting`：迁移后只写 `filterBy`，武器可不再带 `targetFaction`
- Admin / 展示 / design 02–05 / 单测
