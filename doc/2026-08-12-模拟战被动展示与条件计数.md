# 模拟战被动展示与条件计数修复

> 日期：2026-08-12  
> 状态：已实现  
> 与 `design/02-名词解释.md` §十四 同步

## 设计共识

1. 条件计数 = 全子树出现次数（affix 实例 + 各实体 fixedAffixes）；同实体固定+动态同 ID 各算各的  
2. 本方案补 `repeatable:false` 挂载拦截（已拥有含 fixed 不可再挂）  
3. `has_affix` / `affixIds` 与条件同一套  
4. 展示：模拟战 + 正式局共用卡面/悬浮窗一起改  
5. BD 条件文案带进度 `（现 k）`；制作页无树可无  
6. 开战冻结条件；BD preview 实时  
7. 未生效不注入 passiveSources，仅 UI 浅色展示

## 修改点摘要

### 1. 计数

- `data.ts`：`countMatchingAffixesInSubtree` / `evaluateSubtreeCondition`  
- `engine.ts`：条件判定与 `collectAffixIds` 含 fixedAffixes  

### 2. 挂载

- `canMountAffix`：`!repeatable && owned.has(id)` 拒绝  

### 3–5. 展示

- 卡面/tooltip 被动逐行 + 条件进度 + `.sb-passive-inactive`  
- 动态词条：`(used/slots 槽位)`
