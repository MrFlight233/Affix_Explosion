# 词条分类「商店筛选中显示」开关

> 日期：2026-07-30  
> 状态：已实现  
> 修订：仅影响正式局商店词条分类 Chip；不影响全物品池、模拟对战、管理端筛选

## 目标

在词条分类（`CategoryDef` / `categories` 表）上增加 **「商店筛选中显示」** 布尔字段。勾选则出现在正式局商店的词条分类筛选 Chip；不勾选则不出现。默认勾选。

## 字段约定

| 层 | 命名 | 类型 | 默认 |
|----|------|------|------|
| TS | `showInFilter` | `boolean` | `true` |
| DB | `show_in_filter` | `INTEGER` 0/1 | `1` |

作用范围：

- **影响**：正式局商店（`officialExplore` → `renderPoolFiltersHtml(..., { forShop: true })`）
- **不影响**：全物品池、模拟对战物品池、管理端词条列表筛选 Chip；词条表单分类下拉仍含全部分类
- **叠加**：商店 Chip = `showInFilter` ∩ 货架有货（见 `doc/2026-07-31-商店筛选有货才显示.md`）

## 实现要点

### 数据层

- `CategoryDef.showInFilter`
- `getAffixFilterCategories()`：返回**全部分类**（工具/管理端/模拟战）
- `getShopAffixFilterCategories()`：仅 `showInFilter !== false`，供正式局商店
- DB 列 `show_in_filter` + `migrateCategoryShowInFilter`

### UI

- `renderPoolFiltersHtml(state, { forShop: true })` 使用商店专用分类列表
- 分类管理弹窗文案：「商店筛选中显示」；未展示标 `[商店筛选隐藏]`
