# 实体被动总开关 + 负重加成 (loadBonus)

> 日期：2026-07-28  
> 状态：已实现  
> 聚合规则：与其它被动一致，加到最近启动端的 maxLoad  
> 字段名：`loadBonus` / 列 `load_bonus`

## 目标

1. Admin 实体「被动加成」区：增加与词条相同的有/无总开关；无则隐藏字段，保存时清零相关被动值。
2. 实体与词条均新增被动属性负重加成 `loadBonus`：子树累加后，启动端有效负重上限 = `maxLoad + ΣloadBonus`（含启动端自身，受总开关约束）。

明确不做：不改主游戏面板拖拽；不把负重加成做成「直接父实体」聚合。

## 选型或根因

| 项 | 现状 | 目标 |
|----|------|------|
| 实体被动 UI | 字段常显，无总开关 | 对齐词条 `hasPassiveBonuses` |
| 负重 | 仅用实体自身 `maxLoad` | `maxLoad + ΣloadBonus`（启动端） |
| 聚合目标 | 其它被动 → 最近 starter | `loadBonus` 同样 → 最近 starter |

## 实现要点

### 数据模型与 DB

- `project/client/src/game/data.ts`：EntityDef 增 `hasPassiveBonuses`、`loadBonus`；AffixDef 增 `loadBonus`
- `project/server/src/db/schema.ts`：entities/affixes 增 `load_bonus`；entities 增 `has_passive_bonuses`
- `project/server/src/db/seed.ts`：幂等 ALTER + 实体首次回填
- `project/server/src/db/cache.ts`：row↔def
- `entityRepo.ts` / `affixRepo.ts`：INSERT/UPDATE 补列

### Admin

- 实体被动区：`ef-hasPassiveBonuses` + `#ef-passive-fields`（5 字段 + loadBonus）；关则隐藏并清零
- 词条：`#af-passive-fields` 追加 loadBonus；关开关清零含 loadBonus

### 引擎

- `collectFromChildren` 增 `totalLoadBonus`
- 实体/词条/`starter` 自身：仅 `hasPassiveBonuses===true` 时累加被动（含 loadBonus）
- `maxLoad: edef.maxLoad + collected.totalLoadBonus`
