## 修改点 1：抽出战斗卡只读共用 API

**现状**：`officialCombat` 内联渲染/绑定；`runReview` 另写一套 `build` 模式裸卡 + 自建折叠，悬浮窗无被动 unit。

**期望**：结算与历史回顾的双方 BD 与战斗壳同款卡片（`mode=battle`）与悬浮窗。

**原因**：可通用则共用，避免两套展示数值不一致。

**实现**：

- [`project/client/src/ui/officialCombat.ts`](../project/client/src/ui/officialCombat.ts)
  - `renderSlotsAsBattleCards`
  - `normalizeDeploySlotsInPlace`
  - `bindReadonlyBattleCardUi`（折叠 + `bindSbTooltips`）
  - `bindOfficialCombatInteractions` 改为调用上述共用绑定

## 修改点 2：runReview 改用共用 API

**现状**：`renderSideBd` 用 `renderEntityCard(..., 'build')` 且无 `previewBdRuntimes`。

**期望**：深拷贝 BD → normalize → `previewBdRuntimes` → `renderSlotsAsBattleCards`；绑定走 `bindReadonlyBattleCardUi`。

**原因**：与战斗/BD 预览同源，含装备被动。

**实现**：[`project/client/src/ui/runReview.ts`](../project/client/src/ui/runReview.ts)；design `01` / `DESIGN-正式局` 已同步。
