# 模拟对战功能方案

## 概述

模拟对战是管理员专用的 BD 测试与战斗模拟工具。允许自由组建玩家和敌人的构筑，选择战斗回合设定槽位限制并对齐对战池，在不消耗金币的情况下运行战斗模拟。

## 入口

- 管理员登录后在主菜单看到"模拟对战"按钮
- 非管理员用户不可见此按钮
- 页面独立于正式游戏，不影响存档

## 核心功能

### 组建阶段

- **回合选择器**：仅可选战斗回合（2/4/6/8/10），与正式局对战池 `round` 一致。第一层槽位上限 = `floor((round+1)/2)`（即 1/2/3/4/5），与正式局相同。
- **物品池**：展示全部 57 实体 + 62 词条，可搜索、按类别筛选、按实体/词条 Tab 切换。不做回合价值过滤。
- **玩家/敌人 BD 面板**：左右并排，各自独立。显示实体树（含固定词条标签、属性行、子实体区、动态词条折叠区）。
- **交互方式**：纯拖拽。物品池→BD 区添加；BD 内部拖拽重排/换父级；BD→物品池移除。

### 战斗阶段

- 点击"开始模拟战斗"切换到全屏战斗视图
- 双方单位面板并排显示，紧凑纯数字布局
- 实时刷新 HP、耐力、武器倒计时
- 支持暂停和速度调整（0.5x/1x/2x）
- 战斗日志实时追加
- 战斗结束后可返回编辑，BD 完整保留

## 技术要点

### 文件结构

- `project/client/src/game/engine.ts` — `runSimCombat()` 方法，`calculateCombatSnapshots(slots?)` 参数化，`_runBattleCore()` 提取
- `project/client/src/ui/sim-battle.ts` — 主 UI 文件（约 800 行），闭包模式
- `project/client/src/main.ts` — 入口按钮
- `project/client/src/ui/dragDrop.ts` — 新增 `'sim-battle'` 拖拽类型

### Slot 校验

独立于 engine 的槽位校验逻辑 `canPlaceInSlot()`，使用 `getFirstLayerSlots(state.round)`，与正式局公式一致。

### 战斗引擎复用

`runSimCombat()` 复用 `_runBattleCore()`，与正式战斗使用完全相同的战斗逻辑。区别仅在于：不调用 `generateEnemyBD()`、不计算金币/生长/存档。

### 拖拽系统

复用 `makeDraggable`/`makeDropZone`，通过 `DragEvent.dataTransfer` 传递 defId/type/source 信息。物品池和 BD 树各自绑定 dragstart/drop 事件。
