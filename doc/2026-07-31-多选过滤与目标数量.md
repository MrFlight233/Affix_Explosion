# 主动动作：多选过滤 + 统一排序 + 合并池取 N

> 供其它智能体执行。设计真相：`design/02`「针对系统」、`design/03` 主动字段、`design/04` targeting_modifier、`design/05` 第三节。

## 目标

- AoE：**合并池取 N**（可全部）
- **一个 `sortBy`**；缺省 **`random`**
- 删除配置/展示：`targetType`、独立 `priorityTarget`/`targetOrder`
- `filterBy: string[]`；`targetCount`；阵营含 **`自己`**

## 验收要点

1. Admin 可配场景表 1–8 且战斗表现正确
2. 敌人+站位中间+N=1 → 队形正中；站位2 → 第 2 格
3. hp_pct_asc ≠ hp_asc（满血坦克 vs 残血玻璃）
4. 无近战/远程配置；旧 targetType 不影响战斗
5. 卡/悬停/池/日志与 Admin 摘要一致
