## 目标

落地正式局规则与工作台 UI（方向 B + 拖拽流转交互收口），不含模拟战/Admin。

## 任务拆分

1. **引擎**：`round` 改为设计回合 1–10（奇探偶战）；金币/槽位公式；网络错误与空池分离；本局 `battles[]`；去掉 growth 发奖依赖（字段可暂留兼容）
2. **存档**：持久化 events/visited/battles/开战快照；自动存节点；通关归档并删活跃档
3. **历史 API**：`run_history` 表 + CRUD
4. **UI panels**：探险壳方案 B（左 BD / 右上情景 / 右下仓库）+ 竖横分界线；战斗三栏；结算页
5. **main 开始页**：新游戏/继续 + 历史回顾、全物品池独立按钮；有档时删档
6. **CSS**：`--fg-*` token + splitter

## 验收要点

- 新局 90 金 + 进回合 1 探险再 +10
- 槽位 floor((r+1)/2)；第 10 回合战后进结算
- 胜 floor((r+1)/2)×5；负 0；空池满奖结束态
- 网络失败留探险可重试
- 商人 → BD/仓库购买；BD/仓库 → 商人出售；仓库右下常驻
- 拖分界线调面积；刷新后比例保持
- 通关后继续游戏不可用；历史可查
