# Admin 过滤区三行横排布局

> 日期：2026-08-12  
> 状态：已实现  
> 用户选型：**B**（每组各占一行，行内「标题 + 控件」横排）

## 修改点 1：过滤区改为三行横排

### 现状

三处（主动目标 / 被动目标 / 词条主动目标覆写）共用 `project/client/src/game/targetingUtil.ts` 的 `renderFilterSectionHtml`：

- 「目标」与「条件」挤在同一 flex 行
- 「拥有词条」用独立 `adm-field-hint` 标题 + 下方 `popover-selector`，相对成上下叠
- 函数返回多个根节点塞进 `.admin-field`，与左侧「过滤」label 的 flex 子项关系混乱

### 期望

```
过滤  [hint 可选]
      目标　　□… □…
      条件　　□… □…
      [清除过滤 仅词条覆写 extra]
      拥有词条　[chips][+ 添加]
```

- 三组各占一行；每行内部标题与控件横排
- 窄宽时行内 checkbox / chips 仍可 `flex-wrap`，但不把标题甩到控件上方
- 三处 Admin 页观感一致；读写逻辑不变

### 原因

配置时扫一眼即可对齐三类过滤；竖向叠标题浪费编辑区高度，且「拥有词条」与前两组交互层级不一致。

### 实现

#### `project/client/src/game/targetingUtil.ts` — `renderFilterSectionHtml`

- 用单一根包裹：`<div class="adm-filter-section">…</div>`
- 结构：
  - 可选 `hint`（保留现有文案）
  - `.adm-filter-row`：标题「目标」+ `filterCheckboxesRow(…, FACTION_FILTER_OPTIONS)`
  - `.adm-filter-row`：标题「条件」+ `filterCheckboxesRow(…, EXTRA_FILTER_OPTIONS)`
  - 可选 `extra`（词条覆写的「清除过滤」）紧跟条件行后
  - `.adm-filter-row`：标题「拥有词条」+ `renderPopoverSelector(id, '', …)`（不再单独 `adm-field-hint` 标题行）
- 标题用 `<span class="adm-filter-row-title">`，与 checkbox 同一 flex 行
- 「任意一个即匹配」并入行标题 `title` 属性，避免再占一整行

#### `project/client/styles/global.css`

新增：

```css
.adm-filter-section { flex: 1; min-width: 0; display: flex; flex-direction: column; gap: 4px; }
.admin-field:has(.adm-filter-section) { align-items: flex-start; }
.adm-filter-row { display: flex; flex-wrap: wrap; align-items: center; gap: 2px 0; }
.adm-filter-row-title { margin-right: 8px; white-space: nowrap; font-weight: 600; font-size: 12px; flex-shrink: 0; }
.adm-filter-row .popover-selector { flex: 1; min-width: 0; margin: 0; padding: 0; }
.adm-filter-row .popover-selector > label:empty { display: none; }
```

不改全局 `.popover-selector` 默认块级样式。

#### 调用点 — 不改业务，仅受益

| 位置 | 文件 |
|------|------|
| 主动目标 | `admin.ts` `ef-tc-filter` |
| 被动目标 | `adminPassiveBonuses.ts` `*-ptc-filter` |
| 词条主动目标覆写 | `admin.ts` `af-tm-filter` + `extra` 清除过滤 |

控件 `name` / popover `id`、读写合并逻辑不动。
