# 探险壳过长区域可滚动

> 日期：2026-08-14  
> 状态：已实现

## 修改点 1：右上情景区（事件 / 工匠 / 非货架事件面板）可滚动

**现状**：`.fg-layout #event-area` 为 `overflow: hidden`，盖过旧的 `#event-area { overflow-y: auto }`。工匠展开大卡片被裁切且无法滚动。

**期望**：右上栏内容超高时可纵向滚动；标题、强化按钮、结束事件均可滚到。

**原因**：右上高度由 `--fg-top-pct` 固定，内容（尤其工匠 BD 式卡片）可变长，必须有滚动出口。

**实现**：

- [`project/client/styles/global.css`](../project/client/styles/global.css)：`.fg-layout #event-area` 改为 `overflow-y: auto; overflow-x: hidden;`
- 战斗壳 `#main-layout.fg-combat #event-area` 仍 `overflow: hidden`，滚动由 `.sb-battle-side` 承担，不改
- [`design/08-正式局设计系统.md`](../design/08-正式局设计系统.md)：补一句右上情景区过长可纵向滚动

## 修改点 2：验收 BD / 仓库 / 商人（已有滚动则只验证）

**现状**：

| 区域 | 滚动落点 | 状态 |
|------|----------|------|
| 商人货架 | `#fg-shop-item-list` | 已有 |
| 出场 BD | `#fg-player-bd > .sb-deploy-area` | 已有 |
| 仓库 | `#fg-warehouse-area > .sb-deploy-area` | 已有 |
| 事件/工匠 | `#event-area` | 本修 |

**期望**：四区过长均可滚；若 BD/仓库验收失败，再补 flex 高度链断点。

**原因**：避免只修工匠后仍有其它栏「看不见」。

**实现**：手工验收；默认不改 BD/仓库 CSS。
