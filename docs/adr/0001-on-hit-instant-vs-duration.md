# 命中效果拆成即时与持续，百分比相对上限

命中不再是「战斗中任意永久改运行时字段」的口子。即时只改当前池与本轮 CD；底盘（上限、回复、武器耗时/耐耗、重压）必须带寿命。百分比分母改为属性上限（武器类用开战快照），废弃以本次伤害量为通用 percent 基准，以免无伤控制失效、并与「双即时≈吸血」的配置模型对齐。持续同一性以**名称**为轨道（同名后写全量覆盖；Tick 壳施加与同名覆盖均立即跳并重置间隔），毒用 Tick 壳打出即时而非直接改当前池，以守住白名单。`buffKey` 为跟名存储的遗留字段。细则见 [doc/2026-08-13-持续同名完全覆盖与Tick重跳.md](../../doc/2026-08-13-持续同名完全覆盖与Tick重跳.md)。
